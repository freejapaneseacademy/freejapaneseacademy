# Cloudflare Pages deployment

This Astro site is deployed from GitHub to Cloudflare Pages.

- GitHub repository: `freejapaneseacademy/freejapaneseacademy`
- Production branch: `main`
- Framework: Astro (static)
- Build command: `npm run build`
- Output directory: `dist`
- Root directory: repository root (blank in Cloudflare settings)
- Project name: `free-japanese-academy`
- Production domain: `https://free-japanese-academy.pages.dev`

Changes pushed to `main` trigger a production build; preview branches can receive preview deployments. The JLPT course content is presently a Phase 1 demonstration, not a completed curriculum.
