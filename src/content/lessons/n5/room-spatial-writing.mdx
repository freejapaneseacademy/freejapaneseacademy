## A note for a visiting student

You are helping a visiting student find things in a **fictional** school study room. Write a short note about the layout. Your reader cannot see the room, so name the reference point each time.

> 部屋（へや）に机（つくえ）があります。 — There is a desk in the room.  
> 机の上（うえ）に本（ほん）があります。 — There is a book on the desk.  
> 机の隣（となり）に先生（せんせい）がいます。 — There is a teacher beside the desk.

The first sentence introduces the desk. The next two use it as a reference point. This makes a connected description rather than an unrelated list.

## 1. Build a spatial sentence

**Reference noun + の + position + に + entity + が + あります／います。**

| Japanese | Reading | Meaning |
| --- | --- | --- |
| 上 | うえ | above / on top |
| 下 | した | below / underneath |
| 前 | まえ | in front of |
| 後ろ | うしろ | behind |
| 中 | なか | inside |
| 隣 | となり | beside / next to |

**机の下にかばんがあります。** — There is a bag under the desk.  
**部屋の中に学生（がくせい）がいます。** — There is a student inside the room.  
**机の前に先生がいます。** — There is a teacher in front of the desk.

The **の** links the reference noun to its relative position: 机の上 means “the top of the desk / on the desk.” **に** marks the resulting location; **が** identifies what exists there. In this pattern, **あります** normally describes objects and **います** describes people and animals.

## 2. Keep the viewpoint consistent

Imagine a door at the front of the room and a desk inside. Your note could say:

> 部屋に机があります。  
> 机の上に本があります。  
> 机の下にかばんがあります。  
> 机の隣に学生がいます。

Translation: There is a desk in the room. There is a book on the desk. There is a bag under the desk. A student is beside the desk.

A reference is essential. **上に本があります** can be understood when a location is already established, but **机の上に本があります** is clearer to a new visitor. **前** and **後ろ** depend on the orientation of the referenced item; a diagram or shared viewpoint may be needed in real situations.

### Repair common mistakes

| Problem | Less suitable | Better |
| --- | --- | --- |
| Missing link | 机上に本があります。 | 机の上に本があります。 |
| Wrong existence verb | 机の下にかばんがいます。 | 机の下にかばんがあります。 |
| Wrong verb for a person | 机の隣に先生があります。 | 机の隣に先生がいます。 |
| Wrong location marker | 机の上が本にあります。 | 机の上に本があります。 |

The compact compound 机上（きじょう） exists in Japanese, but is not the beginner-friendly spatial construction taught here; it is not inherently ungrammatical.

## 3. Write, then revise

**Controlled substitution.** Start with **机の上に本があります。** Change 上 to 下. Then change 本 to 先生 and change the existence verb. Models: **机の下に本があります。** / **机の上に先生がいます。** The latter is grammatically possible but unlikely in an ordinary classroom; for a realistic description use **机の隣に先生がいます。**

**Guided reconstruction.** A room has a desk; a bag is under it; a student is beside it. Write three sentences before revealing the model in the workshop.

**Independent composition.** Write **two to five connected sentences** about your own invented room. Include a reference object, at least two different spatial positions, and one sentence with あります or います. If you include both an object and a person, check the verb contrast. Use kana for kanji you have not yet learned.

## 4. Self-review, not machine grading

Review four criteria: **(1)** connected and clear reference points; **(2)** correct の and に; **(3)** が plus appropriate あります／います; **(4)** readable kana/kanji and polite endings. The draft is saved only when you press Save, on this browser/device. It is not sent to a teacher and is not automatically scored. The eight recognition questions below are separately scored as written recognition, not as a JLPT grade.

Optional speaking: read your own room note slowly, pointing to each imagined location. No audio or pronunciation assessment is provided in this written lesson.
