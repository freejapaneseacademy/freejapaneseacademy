## Mission: welcome a visitor to a small room

Imagine you are showing a guest around a **fictional study room**. You will practise as both the host and the guest. This speaking lesson is **optional**: reading silently is a valid alternative, and no microphone, upload, or pronunciation scoring is used. For audio-first study, use the separate chapter L06 guided-tour recording **only when its authentic playback and rights checks are verified**; this page does not embed or claim that recording.

### Useful language

| Japanese | Reading | Meaning |
| --- | --- | --- |
| 部屋 | へや | room |
| 机 | つくえ | desk |
| 椅子 | いす | chair |
| 本棚 | ほんだな | bookshelf |
| 窓 | まど | window |
| かばん | かばん | bag |
| 猫 | ねこ | cat |
| 上 | うえ | above / on top |
| 下 | した | below / under |
| 前 | まえ | in front of |
| 後ろ | うしろ | behind |
| 中 | なか | inside |
| 隣 | となり | next to |

**Pattern:** <span lang="ja">[place] に [thing] が あります。</span> says an inanimate thing is at a place. For a person or animal, use **います**. To say “on the desk,” put **の** between the reference object and position: <span lang="ja">机の 上に</span>. The location particle **に** comes after the whole location phrase. A previously mentioned object may be introduced with **は**: <span lang="ja">かばんは どこに ありますか。</span> (“Where is the bag?”).

### Scene A — the guest asks about the bag

**Known fictional layout:** a desk is in the room; a bag is under the desk; a bookshelf is beside the window. The dialogue does **not** identify the bag's owner.

| Speaker | Japanese | Meaning |
| --- | --- | --- |
| Guest | すみません。かばんは どこに ありますか。 | Excuse me. Where is the bag? |
| Host | 机の 下に あります。 | It's under the desk. |
| Guest | 本棚は どこに ありますか。 | Where is the bookshelf? |
| Host | 窓の 隣に あります。 | It's next to the window. |
| Guest | ありがとうございます。 | Thank you. |
| Host | どういたしまして。 | You're welcome. |

Notice that **下** (under) and **隣** (beside) are different relationships. <span lang="ja">窓の 隣</span> identifies the window as the reference point; it does not mean “inside the window.”

### Scene B — the host introduces the room

**Known fictional layout:** a cat is in front of the chair; a book is on top of the desk. These are invented scene facts, not observations of a real room.

| Speaker | Japanese | Meaning |
| --- | --- | --- |
| Host | ここは 私の 部屋です。 | This is my room. |
| Host | 机の 上に 本が あります。 | There is a book on the desk. |
| Host | 椅子の 前に 猫が います。 | There is a cat in front of the chair. |
| Guest | 猫は 椅子の 前に いますか。 | Is the cat in front of the chair? |
| Host | はい、います。 | Yes, it is. |

**Why います?** A cat is an animal, so the normal existence verb is **います**. A book is an object, so use **あります**. Do not use <span lang="ja">猫が あります</span> for a living cat. A location phrase with **の** is a relationship, not an ownership claim.

### Rehearsal ladder

1. **Observe:** Read the guest's first question and the host's reply in Scene A. Point to an imaginary desk, then below it. Notice the polite question ending **か**.
2. **Switch:** Take the host's lines, then the guest's lines. Use the interactive role switcher below. Speak slowly if you wish; reading silently is also acceptable.
3. **Substitute:** Change <span lang="ja">机の 下</span> to <span lang="ja">机の 上</span> in a **new imaginary arrangement**. Say <span lang="ja">机の 上に かばんが あります。</span> (“There is a bag on the desk.”). This is a new practice fact, not a correction to Scene A.
4. **Extend:** Describe a fictional room in two to four short sentences. Include one object with **あります**, one animal or person with **います**, and at least one position word. You may use <span lang="ja">本棚の 中に 本が あります。</span> (“There are books inside the bookshelf”) or <span lang="ja">椅子の 後ろに 猫が います。</span> (“A cat is behind the chair”) as **new** imaginary examples.

### Independent roleplay

Your partner asks <span lang="ja">机は どこに ありますか。</span> (“Where is the desk?”). Choose a fictional location, such as <span lang="ja">窓の 前に あります。</span> (“It's in front of the window.”). Then ask about a cat. Switch who asks and who answers. Your answers can differ from the model because this is a **new fictional room**; make the imagined arrangement consistent.

### Self-review rubric

After rehearsal, check whether you (1) used **の** between a reference object and position word; (2) used **に** after the location; (3) used **あります** for objects and **います** for animals or people; and (4) switched roles while keeping the exchange polite and understandable. These are self-reflection criteria, **not a certified speaking or pronunciation grade**. The scored check below tests written recognition only.
