## A message for the lost-and-found desk

You find a notebook beside a classroom door. You want to describe it and ask who owns it, without assuming an owner. In this writing lesson you will produce **two to five connected Japanese sentences**. Use fictional names and objects, not real identifying information.

### 1. Read a model exchange

**A:** <span lang="ja">これは ノートです。</span> — This is a notebook.

**A:** <span lang="ja">この ノートは だれのですか。</span> — Whose notebook is this?

**B:** <span lang="ja">それは ミナさんのです。</span> — That is Mina's.

**A:** <span lang="ja">そうですか。ありがとうございます。</span> — I see. Thank you.

The speakers are standing in different positions. A uses **これ** for an object near A; B calls the same object **それ** because it is nearer A than B. These words depend on speaker perspective, not a permanent property of the object.

### 2. Notice the grammar before you write

| Pattern | Example | Why it works |
| --- | --- | --- |
| **これ / それ / あれ** + は | <span lang="ja">これは ペンです。</span> — This is a pen. | The demonstrative itself replaces a noun. |
| **この / その / あの** + noun + は | <span lang="ja">その ペンは だれのですか。</span> — Whose pen is that? | The demonstrative must modify a following noun. |
| person + **の** + です | <span lang="ja">ユキさんのです。</span> — It's Yuki's. | The understood object can be omitted after の. |
| **だれの** + ですか | <span lang="ja">あれは だれのですか。</span> — Whose is that over there? | だれの asks for an owner. |

**Common mix-up:** <span lang="ja">このは ペンです</span> is not grammatical: **この** needs a noun. Write <span lang="ja">これは ペンです。</span> or <span lang="ja">この ペンは わたしのです。</span> instead. **だれの** asks whose, not what; **何（なん）ですか** asks what something is.

### 3. Build your own message in stages

**Controlled substitution.** Replace the object in <span lang="ja">これは ノートです。</span> with <span lang="ja">かさ</span> (umbrella), <span lang="ja">本（ほん）</span> (book), or <span lang="ja">ペン</span> (pen). Keep **です** and the final **。**.

**Guided reconstruction.** Put these parts together: <span lang="ja">この / かばん / は / だれの / ですか</span>. A correct result is <span lang="ja">この かばんは だれのですか。</span> (“Whose bag is this?”). Then answer with a fictional owner: <span lang="ja">アキさんのです。</span> (“It's Aki's.”)

**Meaning check.** <span lang="ja">あの かばん</span> refers to a bag away from both speakers. <span lang="ja">その かばん</span> typically refers to one near the listener. In a written scenario, describe where the object is so that the demonstrative is justified.

### 4. Independent writing task

Imagine you are at the school reception desk. A **blue notebook** is on the counter near you; your classmate is across the counter. Write **two to five connected polite Japanese sentences**. Identify the notebook, ask who owns it, and give a plausible answer using a fictional name (for example, ミナさん). You may add a polite acknowledgment.

A possible model:

> <span lang="ja">これは 青い ノートです。</span> — This is a blue notebook.
>
> <span lang="ja">この ノートは だれのですか。</span> — Whose notebook is this?
>
> <span lang="ja">それは ミナさんのです。</span> — That's Mina's.
>
> <span lang="ja">ありがとうございます。</span> — Thank you.

**Alternatives:** You may omit 青い, use ペン or 本 if you clearly adapt the scenario, or replace ミナさん with another fictional name. **わたしのです** (“It's mine”) is also grammatical when the speaker owns it. Your text does not need to match the model word for word.

### 5. Self-review rubric (not automatic grading)

| Criterion | Check yourself |
| --- | --- |
| Meaning and cohesion | Did you identify an object, ask its owner, and provide a consistent answer in 2–5 sentences? |
| Demonstratives | Is これ/それ/あれ used without a following noun, or この/その/あの directly before one? Is the distance perspective sensible? |
| Ownership | Did you use **だれのですか** to ask and **name + のです** or **わたしのです** to answer? |
| Readability and politeness | Are sentences understandable, with は, です/ですか and appropriate punctuation? |

Revise after comparing your draft with the model. The writing workshop below saves a draft **only in this browser when you press Save**; it does not send your writing to a teacher or grade Japanese composition. The short recognition quiz checks specific written forms separately.

### 6. Transfer and optional oral rehearsal

Write a second version where the item is far from both people: <span lang="ja">あれは かさです。あの かさは だれのですか。</span> (“That over there is an umbrella. Whose umbrella over there is it?”) You can read your sentences aloud for private rehearsal, but no pronunciation evaluation or recording is performed here. Genuine audio listening belongs to the separate L06 activity.
