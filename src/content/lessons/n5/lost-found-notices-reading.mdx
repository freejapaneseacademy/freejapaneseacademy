## A real reading task: two notices, two different days

**Can-do:** identify an object and ask who it belongs to. Imagine two original, fictional notices posted by a school's lost-and-found desk. They are **written reading material**, not recordings. The names are invented; do not infer anything about real people.

**Note A — after the art club (Monday)**

| Japanese lost-and-found note | Meaning |
|---|---|
| 月曜日（げつようび）。青い（あおい）かさを あずかっています。 | Monday. We are holding a blue umbrella. |
| この かさは ミナさんのでは ありません。 | This umbrella is not Mina's. |
| レンさんの かさです。 | It is Ren's umbrella. |
| かさは うけつけに あります。 | The umbrella is at reception. |

**Note B — after the library club (Tuesday)**

| Japanese lost-and-found note | Meaning |
|---|---|
| 火曜日（かようび）。赤い（あかい）ノートと 白い（しろい）けしゴムを あずかっています。 | Tuesday. We are holding a red notebook and a white eraser. |
| その ノートは アキさんのです。 | That notebook is Aki's. |
| けしゴムは だれのですか。まだ わかりません。 | Whose eraser is it? We do not know yet. |
| ノートと けしゴムは としょしつの つくえに あります。 | The notebook and eraser are on the library room's desk. |

## 1. Read for a specific fact, not every word

Start with **what** was found: <span lang="ja">青い かさ</span> (blue umbrella) on Monday, and <span lang="ja">赤い ノートと 白い けしゴム</span> (red notebook and white eraser) on Tuesday. The notes explicitly name **レンさん** as the umbrella's owner and **アキさん** as the notebook's owner. The eraser's owner is **not yet known**.

The phrase <span lang="ja">あずかっています</span> means “we are keeping/holding (an item)” in these notices. You need only recognize its function here; the verb's conjugation is not tested. Similarly, <span lang="ja">あります</span> gives an item's location; location grammar is studied in the next chapter.

## 2. Track demonstratives and ownership

In Note A, <span lang="ja">この かさ</span> means “this umbrella” and refers back to the **blue umbrella** just mentioned. It does not mean “this is an umbrella”: <span lang="ja">この</span> must modify a noun. Compare <span lang="ja">これは かさです。</span> (“This is an umbrella”), where <span lang="ja">これ</span> stands alone.

In Note B, <span lang="ja">その ノート</span> (“that notebook”) refers to the **red notebook** already introduced. In written discourse, <span lang="ja">その</span> can point back to a previously mentioned item; it does not require a picture showing physical distance.

The owner pattern is **person + の + object**: <span lang="ja">レンさんの かさ</span> = Ren's umbrella. When the object is already clear, <span lang="ja">アキさんのです</span> = “It's Aki's.” The phrase <span lang="ja">ミナさんのでは ありません</span> rejects Mina as the owner of *this particular umbrella*, not of all umbrellas.

## 3. Evidence versus guessing

| Question | Answer | Exact evidence |
| --- | --- | --- |
| Whose blue umbrella? | Ren's | <span lang="ja">レンさんの かさです。</span> |
| Is it Mina's? | No | <span lang="ja">ミナさんのでは ありません。</span> |
| Whose red notebook? | Aki's | <span lang="ja">その ノートは アキさんのです。</span> |
| Whose eraser? | Unknown | <span lang="ja">まだ わかりません。</span> |
| Where is the umbrella? | Reception | <span lang="ja">うけつけに あります。</span> |

**Do not assume** the eraser belongs to Aki merely because the notebook does. The note names only the notebook's owner. Similarly, “on the library room's desk” is a location, **not** a claim that the library owns the objects.

## 4. Guided reading: locate, quote, explain

Try this before the scored check: *Which day mentions a notebook?* Find <span lang="ja">火曜日</span> in Note B and <span lang="ja">赤い ノート</span> in the same line. Answer “Tuesday” and quote <span lang="ja">火曜日。赤い ノート…</span>. Then ask “What is still unknown?” The direct evidence is <span lang="ja">けしゴムは だれのですか。まだ わかりません。</span>.

## 5. Independent transfer

Write a three-line fictional lost-item notice using an object, a named owner or <span lang="ja">まだ わかりません</span>, and a location. For example: <span lang="ja">白い ほんが あります。これは ユイさんのです。うけつけに あります。</span> Compare your work with the model in the practice activity. Check that you never invent an owner for an unknown item.

The ten-question reading check below tests **only written evidence**. It does not assess listening, pronunciation or spoken fluency.
