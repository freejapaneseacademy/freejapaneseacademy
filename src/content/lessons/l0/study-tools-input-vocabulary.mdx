## At the study desk

**Chapter Can-do:** Enter Japanese using a keyboard and control reading aids. This vocabulary lesson builds on Aya and Ken's keyboard-help scene from Lesson 01. The aim is to recognize and use short study expressions **in context**, not to memorize an operating system's exact menu labels.

Aya wants to type a Japanese label. She has an English-letter keyboard and an unfamiliar word on screen. Ken explains two different kinds of support: **にゅうりょく** (input) helps produce Japanese characters, while **ふりがな** (furigana) helps read kanji that are already displayed.

## 1. Words for what you do

| Japanese | Reading support | Meaning and use |
| --- | --- | --- |
| <span lang="ja">にほんご</span> | nihongo | Japanese language; in <span lang="ja">にほんごで</span>, “in Japanese” |
| <span lang="ja">もじ</span> | moji | written character or letter |
| <span lang="ja">かな</span> | kana | hiragana and katakana collectively |
| <span lang="ja">にゅうりょく</span> | nyūryoku | input or entering text; often used in software instructions |
| <span lang="ja">かく</span> | kaku | to write; <span lang="ja">かきます</span> is the polite non-past form |
| <span lang="ja">よむ</span> | yomu | to read; <span lang="ja">よみます</span> is the polite non-past form |
| <span lang="ja">ふりがな</span> | furigana | small kana showing how to read kanji |
| <span lang="ja">へんかん</span> | henkan | conversion, such as changing input into kanji |

**Do not confuse the tools.** Typing `neko` with an enabled romaji-input Japanese IME can produce <span lang="ja">ねこ</span>. Furigana does not do this conversion: <ruby lang="ja">日本語<rt>にほんご</rt></ruby> uses small kana to show the reading of an existing word.

**Pronunciation note:** Latin-letter readings above are optional beginner scaffolds, not substitutes for Japanese writing or audio evidence. This written lesson does not assess spoken pronunciation.

## 2. Classroom requests that actually help

| Expression | Natural meaning in context | When to use it |
| --- | --- | --- |
| <span lang="ja">すみません。</span> | Excuse me. | Politely attract a teacher's attention |
| <span lang="ja">おねがいします。</span> | Please. / I would appreciate it. | Make a contextually understood request |
| <span lang="ja">もういちど おねがいします。</span> | Once more, please. | Ask for a repeated explanation |
| <span lang="ja">ゆっくり おねがいします。</span> | Slowly, please. | Ask someone to slow down |
| <span lang="ja">おしえて ください。</span> | Please tell/show me. | Request instruction or an explanation |
| <span lang="ja">よみかたを おしえて ください。</span> | Please tell me how to read it. | Ask for the reading of written text |

**Meaning versus function:** <span lang="ja">もういちど</span> literally means “one more time”; in <span lang="ja">もういちど おねがいします。</span> the whole expression functions as a **polite request to repeat**. <span lang="ja">ゆっくり</span> means “slowly”; it is not a synonym for “again.”

The particle <span lang="ja">を</span> marks the thing being requested in <span lang="ja">よみかたを おしえて ください。</span>. You do not need to produce this grammar independently yet: recognize the whole phrase as a useful classroom request.

## 3. Read a new exchange

This is original **written** dialogue, not recorded listening material.

| Speaker | Japanese | English |
| --- | --- | --- |
| Aya | <span lang="ja">すみません。にほんごで かきたいです。</span> | Excuse me. I want to write in Japanese. |
| Ken | <span lang="ja">にほんごの にゅうりょくに してください。</span> | Please switch to Japanese input. |
| Aya | <span lang="ja">「ねこ」と かけました。</span> | I managed to write “ねこ.” |
| Aya | <span lang="ja">この もじの よみかたを おしえて ください。</span> | Please tell me how to read these characters. |
| Ken | <span lang="ja">ふりがなを みて ください。</span> | Please look at the furigana. |
| Aya | <span lang="ja">もういちど おねがいします。</span> | Once more, please. |

Spaces in the Japanese sentences are beginner reading supports. In ordinary Japanese text, spaces are generally omitted. The dialogue deliberately distinguishes **entering text**, **reading text**, and **asking for help**.

## 4. Guided retrieval in three situations

**Situation A — the letters stay Latin.** Aya types `neko`, but sees `neko` instead of <span lang="ja">ねこ</span>. Which tool should she check? **にほんごの にゅうりょく** (Japanese input), not furigana.

**Situation B — she sees unfamiliar kanji.** The screen shows <ruby lang="ja">日本語<rt>にほんご</rt></ruby>. The small kana answer the question “How do I **read** this?” They do not translate the word into English or change what was typed.

**Situation C — Ken speaks too quickly.** Aya can say <span lang="ja">ゆっくり おねがいします。</span> If she missed the entire instruction, <span lang="ja">もういちど おねがいします。</span> is more precise.

## 5. Avoid these common mistakes

- **にゅうりょく** is an action or input mode, not the name of the hiragana alphabet.
- **ふりがな** indicates reading, not meaning. A dictionary or teacher may be needed for meaning.
- **へんかん** means conversion, but not every kana word needs conversion into kanji. <span lang="ja">ねこ</span> is a valid kana label for this task.
- **おねがいします** alone relies on shared context. For a specific request, <span lang="ja">よみかたを おしえて ください。</span> is clearer.
- **もういちど** (“again”) and **ゆっくり** (“slowly”) solve different communication problems.

## 6. Independent use

Imagine that you want to label a cat picture and then read <ruby lang="ja">日本語<rt>にほんご</rt></ruby> on a study page. In English, explain which action uses an IME and which uses furigana. Write one Japanese phrase asking the tutor to repeat, and another asking for a reading.

**Model for self-review:** “I enable Japanese input to type <span lang="ja">ねこ</span>. I use furigana to read <span lang="ja">日本語</span> as <span lang="ja">にほんご</span>. I can say <span lang="ja">もういちど おねがいします。</span> or <span lang="ja">よみかたを おしえて ください。</span>”
