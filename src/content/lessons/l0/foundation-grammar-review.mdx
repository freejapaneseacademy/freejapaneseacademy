## A useful final-foundations habit

At the start of a fictional Japanese class, you find a note you typed yesterday:

> これわ ノトですか。

You meant **“Is this a notebook?”** The reader can guess your meaning, but two spellings need attention. Correct it to **これは ノートですか。** This chapter is not about memorizing another long list. It is about noticing what you already know, repairing one specific error and returning to it later.

By the end of this lesson, you will have a small review plan you can repeat before beginning N5-aligned study. Fluency grows through repeated recognition and retrieval, not through a single perfect quiz.

## 1. Find the function before the form

Read these three original classroom lines.

| Japanese | Meaning | Function |
| --- | --- | --- |
| わたしは ミナです。 | I'm Mina. | Polite introduction |
| これは ノートです。 | This is a notebook. | Polite identification |
| これは ノートですか。 | Is this a notebook? | Polite question |

**AはBです** presents A as a topic and gives information B about it. The particle **は** is pronounced *wa* when marking the topic; **わ** is not its normal written form here. Add **か** after **です** to make the polite noun question. This is a beginner pattern, not a rule for every Japanese question.

**を** marks the direct object in many verb constructions; it does **not** replace は in **これは ノートです**. You only need to recognize that distinction today.

## 2. Check kana length and size

Kana errors can change the word rather than just its appearance.

| Compare | What to notice |
| --- | --- |
| ノト → **ノート** | A notebook uses the katakana long-vowel mark **ー**. |
| きて / **きって** | The small **っ** creates a different rhythm and word; きて can mean “come” (て-form), while きって means “stamp” in this spelling. |
| か / **が** | Dakuten (゛) changes the consonant. |
| せんせい | The ん is part of the written word for “teacher.” |

Read the forms slowly. Do not treat long vowels or small kana as decoration. Optional speaking: say ノート and きって aloud, but there is no recording or pronunciation grade in this written lesson.

## 3. Recognize meaning in context

In a fictional registration conversation, a teacher asks **おなまえは？** (“Your name?”; shortened polite-context question). A student replies **ミナです。** (“I'm Mina.”) The form label **なまえ** means “name,” **くに** means “country,” and **ばんごう** means “number.” These labels are not interchangeable.

The number **なな** is a common reading of seven. Numbers can have more than one reading in Japanese, so choose a form appropriate to the task rather than assuming each numeral has only one pronunciation.

A greeting also depends on its purpose. **こんにちは** is a daytime greeting; **ありがとうございます** expresses thanks. Neither is a universal substitute for the other.

## 4. Use an error-repair loop

Try this sequence with the fictional note:

1. **Notice:** underline これわ and ノト.
2. **Explain:** topic *wa* is spelled **は**; ノート needs **ー**.
3. **Rewrite:** これは ノートですか。
4. **Retrieve:** hide the model and write the correct line from memory.
5. **Revisit:** try again tomorrow, then a few days later if needed.

This is a practical study suggestion, not a scientifically calibrated spaced-repetition schedule. A missed item is a useful clue about what to practice, not a judgment about ability.

## 5. Controlled → guided → independent practice

**Controlled:** choose the correct line: **これは ペンです。** or **これわ ペンです。** Explain why the first uses は.

**Guided:** change **これは ノートです。** into a polite question. Model: **これは ノートですか。** Only the final か changes.

**Independent:** write one real study action you can do in five minutes tomorrow: for example, “Read three kana phrases, cover them, rewrite them, and check one error.” Keep your own notes; do not submit personal information. Use the ten interactive recognition questions below to locate forms worth revisiting.

## 6. A small self-check before N5

You can proceed while still needing review. Ask yourself whether you can read a familiar kana sentence without relying on romaji, distinguish long and short sounds in writing, identify the topic marker, and recover after a mistake. The quiz records written recognition only; it does **not** certify kana fluency, listening skill or N5 readiness. Listening review belongs to this chapter's separate L06 lesson.

**Common misconception:** “I got ten answers correct once, so I have mastered kana.” Immediate recognition and later recall are different. Keep practicing the specific forms you miss, even after a good score.
