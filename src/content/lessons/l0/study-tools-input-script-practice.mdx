## Your task: type and check a classroom label

**Can-do:** Enter Japanese using a keyboard and control reading aids.

Aya is preparing a study card. Her classmate Ken asks her to type a short Japanese word, then show its reading. The goal is **accurate characters**, not memorizing new kanji. The examples are original teaching examples; no operating-system-specific key sequence is guaranteed.

### 1. Input is not conversion

With a Japanese IME set to *romaji input*, type `neko` to obtain <span lang="ja">ねこ</span> (cat). On many IMEs you confirm the hiragana candidate with Enter; conversion menus and shortcuts differ by device. You may leave <span lang="ja">ねこ</span> in hiragana. The possible kanji <span lang="ja">猫</span> is a **recognition example**, not a required Level 0 kanji.

With romaji input, `nihongo` produces <span lang="ja">にほんご</span> (Japanese language). To enter <span lang="ja">日本語</span>, an IME may offer a conversion candidate. Select a candidate only after checking its meaning. Conversion changes the *written representation*; it does not translate or add a reading annotation.

### 2. Character size changes what you typed

| Input in a common romaji IME | Intended kana | Notice |
| --- | --- | --- |
| `ya` | <span lang="ja">や</span> | Full-size や, one mora |
| `kya` | <span lang="ja">きゃ</span> | き + small ゃ, one mora |
| `yu` | <span lang="ja">ゆ</span> | Full-size ゆ |
| `kyu` | <span lang="ja">きゅ</span> | き + small ゅ |
| `kitte` | <span lang="ja">きって</span> | Small っ marks a held consonant, き・っ・て = **three morae** |
| `gakkou` | <span lang="ja">がっこう</span> | Small っ and long お sound; が・っ・こ・う = four morae |

**Compare:** <span lang="ja">きや</span> (full-size や) is not the same spelling as <span lang="ja">きゃ</span> (small ゃ). <span lang="ja">きて</span> (come, te-form) and <span lang="ja">きって</span> (stamp; cut, te-form, depending on context) also differ. These are spelling contrasts, not pronunciation scores.

Some IMEs accept `xtsu` or `ltsu` for an isolated small <span lang="ja">っ</span>. Input methods vary, so verify the *displayed result* rather than assuming every keyboard uses identical commands.

### 3. Furigana: reading aid, not a second word

<ruby lang="ja">日本語<rt>にほんご</rt></ruby> has a main written word, <span lang="ja">日本語</span>, and a small kana reading, <span lang="ja">にほんご</span>. The annotation is called <span lang="ja">ふりがな</span>. In a classroom, <span lang="ja">よみかたを おしえて ください。</span> means “Please tell me the reading.” Furigana can show that reading without replacing the kanji. Some apps support ruby annotations; others require a different workflow.

**Accessibility:** The table and exercises repeat the readings in text, so understanding does not depend on tiny ruby text or color alone.

### 4. Guided practice

1. A teacher asks you to type “cat” in hiragana. Type <span lang="ja">ねこ</span>; do not assume a kanji candidate is mandatory.
2. To type <span lang="ja">きゃ</span> in a common romaji IME, enter `kya`. Check that the second kana is small.
3. For <span lang="ja">きって</span>, inspect the small <span lang="ja">っ</span> before the consonant.
4. For <ruby lang="ja">学校<rt>がっこう</rt></ruby> (school), read the displayed kana as <span lang="ja">がっこう</span>. Recognition only: you do not need to write the kanji from memory.

### 5. Independent self-check

Without looking at the table, type <span lang="ja">にほんご</span>, <span lang="ja">きゃ</span>, and <span lang="ja">きって</span> using a Japanese IME. Compare each character, including size, with the models. If your device has no Japanese IME configured, use the built-in written check below; its questions test kana recognition, not device proficiency.

**Optional tracing:** Trace <span lang="ja">や</span> beside <span lang="ja">ゃ</span> and <span lang="ja">つ</span> beside <span lang="ja">っ</span> on paper. This is self-review, not automatically graded handwriting.

This lesson checks written forms and keyboard concepts. It does not claim speech scoring, listening comprehension, verified typing speed, or independent human Japanese review.
