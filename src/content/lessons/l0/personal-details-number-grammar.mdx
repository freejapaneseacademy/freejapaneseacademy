## Can-do: give a name and read a registration number

Imagine a volunteer helping you register for a beginner class. A name, a country and a two-digit number appear on a card. You can read the number and answer with a short polite statement. This is **written language practice**; the chapter's later listening lesson uses real spoken audio.

## 1. The です frame: a polite statement

In Japanese, **です** is a polite sentence ending used with noun predicates. For a beginner introduction, a useful pattern is **わたしは A です。** (“I am A.”). The topic particle **は** is written *ha* but pronounced *wa* here. You can also answer with **Aです。** when the question makes the subject obvious.

- <span lang="ja">わたしは ミナです。</span> — “I am Mina.”
- <span lang="ja">アキです。</span> — “(My name is) Aki,” as an answer to a name question.
- <span lang="ja">カナダです。</span> — “(It is / I am from) Canada,” **only where the question makes the intended meaning clear**.

**です does not mean “from,” “Japanese,” or “my name.”** The missing context matters. To clearly identify your country of origin in a fuller sentence, you will later learn **〜からきました**. In this lesson, treat country-only answers as short replies to a country question, not complete statements of origin.

## 2. Build numbers from tens and ones

| Number | Japanese | How to parse |
| --- | --- | --- |
| 0 | ゼロ / れい | two common readings; context affects preference |
| 4 | よん / し | よん is a helpful default in number practice |
| 7 | なな / しち | なな avoids confusion in many contexts |
| 10 | じゅう | ten |
| 14 | じゅうよん | ten + four |
| 23 | にじゅうさん | two tens + three |
| 40 | よんじゅう | four tens |
| 68 | ろくじゅうはち | six tens + eight |
| 70 | ななじゅう | seven tens |
| 100 | ひゃく | one hundred |

The basic pattern for 21–99 is **tens + じゅう + ones**. For example, <span lang="ja">にじゅうさん</span> is 20 + 3. **じゅうよん** (14) and **よんじゅう** (40) are easy to reverse. A multiple of ten has no final ones term: **よんじゅう** is 40, not 44. For 11–19, the initial **じゅう** means one ten; do not add **いち** before it.

For 0–100, this is a reliable introductory reading rule, not a guide to all number expressions: dates, ages, phone numbers and counters can have their own conventions.

## 3. Country versus nationality

A country name and a nationality word are related but not interchangeable.

| Country | Nationality expression |
| --- | --- |
| <span lang="ja">カナダ</span> — Canada | <span lang="ja">カナダじん</span> — Canadian person |
| <span lang="ja">アメリカ</span> — United States | <span lang="ja">アメリカじん</span> — American person |
| <span lang="ja">にほん</span> — Japan | <span lang="ja">にほんじん</span> — Japanese person |

In this beginner pattern, **じん** is the nationality suffix. <span lang="ja">カナダです。</span> can be a short answer to “Which country?”; <span lang="ja">カナダじんです。</span> says “(I am) Canadian.” The latter is not a substitute for every question about location or origin. Names and nationalities in the fictional examples are illustrative, not claims about real students.

## 4. Original registration-desk mini scene

**Volunteer:** <span lang="ja">おなまえは？</span> — “Your name?” (brief polite-context prompt)

**Student:** <span lang="ja">ユイです。</span> — “(I'm) Yui.”

**Volunteer:** <span lang="ja">くには？</span> — “Country?” (brief prompt)

**Student:** <span lang="ja">カナダです。</span> — “Canada.”

**Volunteer:** <span lang="ja">ばんごうは？</span> — “Number?”

**Student:** <span lang="ja">にじゅうさんです。</span> — “Twenty-three.”

These elliptical prompts suit a simple fictional form-filling exchange. In formal real-life registration, longer expressions and additional polite wording may be expected.

## 5. Guided written practice

First write the Japanese for **14**, then for **40**. Check the order: **じゅうよん** versus **よんじゅう**. Next write **68** as **ろくじゅうはち**. Using your Japanese keyboard, type **わたしは ユイです。** and check the topic **は**, the katakana name and final **です**.

Finally compare **カナダ** and **カナダじん**. Which identifies a country, and which identifies nationality? Say the distinction in English before completing the scored practice.
