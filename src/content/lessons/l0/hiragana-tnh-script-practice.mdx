## Aki's kana-card workshop

**Can-do:** Read, write and distinguish た–と, な–の and は–ほ. Aki and Ren are arranging classroom kana cards. Ren asks Aki to type each character and compare her handwritten labels with printed models. This lesson assesses **written forms**, not pronunciation, listening or stroke order.

## The complete T/N/H chart

| Position | T | N | H |
| --- | --- | --- | --- |
| a | <span lang="ja">た</span> ta | <span lang="ja">な</span> na | <span lang="ja">は</span> ha |
| i | <span lang="ja">ち</span> chi | <span lang="ja">に</span> ni | <span lang="ja">ひ</span> hi |
| u | <span lang="ja">つ</span> tsu | <span lang="ja">ぬ</span> nu | <span lang="ja">ふ</span> fu |
| e | <span lang="ja">て</span> te | <span lang="ja">ね</span> ne | <span lang="ja">へ</span> he |
| o | <span lang="ja">と</span> to | <span lang="ja">の</span> no | <span lang="ja">ほ</span> ho |

Read down each column, then cover the Latin reading aids. The exceptional spellings *chi*, *tsu* and *fu* are conventional romanization. Some Japanese input methods accept `ti`, `tu`, `hu` as alternate key sequences, but the resulting written characters are still ち, つ and ふ.

## Compare before choosing

- <span lang="ja">ぬ</span> (*nu*) and <span lang="ja">ね</span> (*ne*) begin similarly, but ぬ has a looped lower-right ending while ね has a more upright right-side shape.
- <span lang="ja">は</span> (*ha*) and <span lang="ja">ほ</span> (*ho*) are distinct: ほ has an additional short horizontal stroke on the right.
- <span lang="ja">た</span> (*ta*) and <span lang="ja">な</span> (*na*) both have crossing elements; inspect the right-hand strokes and the whole outline.
- <span lang="ja">ふ</span> (*fu*) and <span lang="ja">ほ</span> (*ho*) share a row, not a shape. <span lang="ja">ち</span> (*chi*) and <span lang="ja">つ</span> (*tsu*) are each **one** kana.

These are **visual recognition cues**, not stroke-order diagrams. Font styles and handwriting may join or separate strokes differently.

## Type Japanese, not Latin letters

Enable a Japanese IME or Japanese keyboard. In romaji-input mode, `ta` should produce <span lang="ja">た</span> when committed as hiragana. On a phone, a kana flick keyboard is also fine. If a conversion menu shows kanji, select the hiragana candidate. The scored answer must be the **Japanese character**; typing `ta` in Latin letters does not count.

**Guided practice:** Type <span lang="ja">た・ち・つ・て・と</span>, then <span lang="ja">な・に・ぬ・ね・の</span>, then <span lang="ja">は・ひ・ふ・へ・ほ</span>. Next alternate <span lang="ja">ぬ・ね・ぬ・ね</span> and <span lang="ja">は・ほ・は・ほ</span>. Compare every character with the chart before proceeding.

## Make familiar word labels

| Written card | Reading | Meaning | Visual check |
| --- | --- | --- | --- |
| <span lang="ja">なつ</span> | *natsu* | summer | つ is one kana |
| <span lang="ja">ふね</span> | *fune* | boat or ship | ふ is not ほ |
| <span lang="ja">ねこ</span> | *neko* | cat | ね is not ぬ |
| <span lang="ja">ほし</span> | *hoshi* | star | ほ is not は |
| <span lang="ja">はな</span> | *hana* | flower or nose, depending on context | Meaning needs context |

Cover the first column, then type each label. These words also reuse earlier K/S-row kana. A kana itself represents a sound, not an independent English meaning.

## Optional copying and accessible alternative

On paper, draw fifteen boxes and copy the chart, or trace the models with a finger. If handwriting is inaccessible, type the same fifteen kana and compare them visually. A printed font cannot verify conventional stroke order; use an appropriately licensed stroke-specific reference for that separate goal.

**Self-review rubric (ungraded):** For each criterion, mark *ready*, *needs revision*, or *not attempted* in your own notes.

1. **Identity:** Can another reader distinguish ぬ/ね and は/ほ?
2. **Completeness:** Did you include every visible component without extra lines?
3. **Legibility:** Is each kana separated and large enough to read?
4. **Revision:** Can you identify one specific shape to improve after comparing with the model?

No automated handwriting judgment or independent reviewer sign-off is claimed.

## Independent check

Complete fifteen Japanese-script input prompts and five printed-form questions. After submitting, inspect the model answers and explanations, then retry weak contrasts. Quiz attempts and lesson completion are stored separately on this device when storage permits. The score measures only written kana recognition and typing.
