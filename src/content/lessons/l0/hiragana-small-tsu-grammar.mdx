## A label changes the message

At the library, Mika prepares an envelope with a <span lang="ja">きって</span> (postage stamp). Ren writes <span lang="ja">きて</span> (“come,” an informal request form) on a reminder for a friend. One **small** character changes the word and its meaning. This lesson explains the written pattern; actual sound discrimination is taught with licensed recordings in Lesson 06.

## Small っ is a timing marker, not a spoken “tsu”

In words such as <span lang="ja">きって</span> (*kitte*), <span lang="ja">きっぷ</span> (*kippu*) and <span lang="ja">ざっし</span> (*zasshi*), small <span lang="ja">っ</span> marks a hold or closure before the following consonant. This is called **gemination**. The hold takes one **mora**, a Japanese timing unit. In <span lang="ja">きって</span>, count <span lang="ja">き・っ・て</span>: three morae. In <span lang="ja">きて</span>, count <span lang="ja">き・て</span>: two. Do not pronounce the small <span lang="ja">っ</span> as a separate *tsu* syllable.

Full-sized <span lang="ja">つ</span> is different: <span lang="ja">つき</span> (“moon”) is <span lang="ja">つ・き</span>, two morae, and begins with the ordinary syllable *tsu*. A small <span lang="ja">っ</span> is not a decorative smaller version of that sound. The beginner examples here place it before consonants; other orthographic uses exist, but are outside today's goal.

| Written form | Mora segmentation | Contextual meaning |
| --- | --- | --- |
| <span lang="ja">きて</span> | <span lang="ja">き・て</span> (2) | “come” (request form, context-dependent) |
| <span lang="ja">きって</span> | <span lang="ja">き・っ・て</span> (3) | postage stamp |
| <span lang="ja">きっぷ</span> | <span lang="ja">き・っ・ぷ</span> (3) | ticket |
| <span lang="ja">がっこう</span> | <span lang="ja">が・っ・こ・う</span> (4) | school |
| <span lang="ja">つき</span> | <span lang="ja">つ・き</span> (2) | moon |

## Long vowels: one longer sound, two timing units

A long vowel occupies **two morae**. Japanese hiragana spelling commonly represents a long *o* with <span lang="ja">おう</span> or <span lang="ja">おお</span>, depending on the **particular word**. In <span lang="ja">こうえん</span> (“park”), <span lang="ja">こ・う</span> spans two morae; in <span lang="ja">おおきい</span> (“big”), the initial <span lang="ja">お・お</span> spans two. You cannot replace <span lang="ja">おお</span> with <span lang="ja">おう</span> just because both can signal a long *o*. Learn each word's spelling.

The sequence <span lang="ja">えい</span> frequently corresponds to a long *e* in common words: <span lang="ja">せんせい</span> (“teacher”) and <span lang="ja">とけい</span> (“clock/watch”). It still uses two written vowel positions and two morae. The exact realization of <span lang="ja">えい</span> can vary by word and speaking style; **do not** assume every adjacent <span lang="ja">え</span> and <span lang="ja">い</span> is pronounced identically. Written pattern identification is not a pronunciation test.

| Word | Relevant spelling | Mora count | Meaning |
| --- | --- | --- | --- |
| <span lang="ja">こうえん</span> | <span lang="ja">こう</span> | <span lang="ja">こ・う・え・ん</span> (4) | park |
| <span lang="ja">おおきい</span> | <span lang="ja">おお</span> | <span lang="ja">お・お・き・い</span> (4) | big |
| <span lang="ja">せんせい</span> | <span lang="ja">せい</span> | <span lang="ja">せ・ん・せ・い</span> (4) | teacher |
| <span lang="ja">とけい</span> | <span lang="ja">けい</span> | <span lang="ja">と・け・い</span> (3) | clock/watch |
| <span lang="ja">がっこう</span> | <span lang="ja">っ</span> and <span lang="ja">こう</span> | <span lang="ja">が・っ・こ・う</span> (4) | school |

## The function in a short library exchange

Mika says <span lang="ja">きってをみてください。</span> — “Please look at the postage stamp.” Ren says <span lang="ja">おおきいですね。</span> — “It's big, isn't it?” The polite request <span lang="ja">みてください</span> contains the object marker <span lang="ja">を</span> after <span lang="ja">きって</span>. The adjective <span lang="ja">おおきい</span> describes size. The sentence context does not change how <span lang="ja">っ</span> or <span lang="ja">おお</span> is written.

A common mistake is copying the spelling of one long-*o* word into another: <span lang="ja">こうえん</span> is **not** written with <span lang="ja">こお</span>, and <span lang="ja">おおきい</span> is **not** written with <span lang="ja">おう</span> at its start. Another mistake is reading <span lang="ja">きって</span> as if it were <span lang="ja">きて</span>; that drops a mora and changes the intended word.

## From rule to independent use

**Controlled:** Point to the small <span lang="ja">っ</span> in <span lang="ja">きって</span>, then identify the full-sized <span lang="ja">つ</span> in <span lang="ja">つき</span>. **Guided:** Count <span lang="ja">が・っ・こ・う</span> and <span lang="ja">と・け・い</span> without counting visible English letters. **Independent:** Explain why <span lang="ja">きて</span> and <span lang="ja">きって</span> cannot be substituted and why both <span lang="ja">こうえん</span> and <span lang="ja">おおきい</span> can contain long *o* while having different spellings.
