## Can-do: greet someone appropriately and follow classroom instructions

You have reached the end of Chapter 01. Imagine arriving at a beginner Japanese class, greeting a teacher, following a request and asking for repetition when you need help. This mixed checkpoint checks what you can **read, choose and hear**; it does not claim to measure conversational fluency.

### 1. Choose greetings for the setting

| Expression | Situation | Note |
| --- | --- | --- |
| <span lang="ja">おはようございます</span> | Polite morning greeting | <span lang="ja">おはよう</span> is a less formal variant. |
| <span lang="ja">こんにちは</span> | Daytime hello | Final <span lang="ja">は</span> is pronounced *wa* here. |
| <span lang="ja">ありがとうございます</span> | Polite thanks | <span lang="ja">ありがとう</span> is less formal. |
| <span lang="ja">すみません</span> | Excuse me / apology | Useful before asking for help. |

A greeting is not a universal translation of “hello.” Time of day, relationship and context matter. <span lang="ja">おやすみなさい</span> is not an ordinary greeting for entering an afternoon class.

### 2. Follow a simple request

In <span lang="ja">入ってください</span> (*haitte kudasai*, please come in), the verb is <span lang="ja">入る</span> (enter). In <span lang="ja">本を開いてください</span> (*hon o hiraite kudasai*, please open the book), <span lang="ja">を</span> marks the object and <span lang="ja">開いて</span> means opening. The pattern **verb て-form + ください** is a polite request, not an English-style command word placed before the verb.

When you miss an instruction, <span lang="ja">すみません。もう一度お願いします。</span> means “Excuse me. One more time, please.” Do not confuse it with a request for a pencil or a break.

### 3. Read four original classroom cards

The cards are fictional and written for this checkpoint:

- **A:** <span lang="ja">おはようございます。田中先生。</span> — Good morning, Teacher Tanaka.
- **B:** <span lang="ja">こんにちは。どうぞ、入ってください。</span> — Hello. Please come in.
- **C:** <span lang="ja">すみません。もう一度お願いします。</span> — Excuse me. One more time, please.
- **D:** <span lang="ja">ありがとうございます。</span> — Thank you.

Find the **exact Japanese phrase** that answers each reading question. Card B invites entry; it does not ask someone to close a book. Card C requests repetition; it does not specify that someone needs a pen.

### 4. Listen to two original classroom conversations

**Track A — Morning arrival:** a learner greets Teacher Tanaka, the teacher invites the learner in, and the learner thanks the teacher. **Track B — Afternoon lesson:** the teacher greets the class and asks everyone to open their books; a learner politely asks for the instruction again.

### 5. Check, write, and review

Answer all fourteen questions. After submitting, read the explanation and exact evidence for each item. Review any weak expression and retry after a break; an 80% practice target is a study suggestion, not an official JLPT score.

For optional ungraded writing, type <span lang="ja">こんにちは</span> and <span lang="ja">もう一度お願いします</span> using a Japanese IME. Self-check (1) readable kana, (2) the conventional final は in こんにちは, (3) correct いちど spelling, and (4) polite register. Optionally shadow one short phrase from the genuine audio privately.
