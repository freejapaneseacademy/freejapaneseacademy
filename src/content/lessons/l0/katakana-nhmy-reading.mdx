## Reading at a small shop

**Can-do:** Read and write katakana in the N, H, M and Y rows. Today you will use those characters to **read explicit information on a shop display**, not guess meanings from shape alone. This is a written reading lesson; no listening or pronunciation is scored.

The fictional shop has a food shelf, a small stationery table, and two visitor name cards. Read the whole display before starting the scored questions.

## Original shop display

| Location or role | Printed katakana | Meaning in this scene |
| --- | --- | --- |
| Food shelf, item A | <span lang="ja">ハム</span> | ham |
| Food shelf, item B | <span lang="ja">バナナ</span> | banana |
| Fabric shelf, item C | <span lang="ja">ヌノ</span> | cloth (practice label; the ordinary Japanese word is usually written 布 or ぬの) |
| Stationery table, note heading | <span lang="ja">メモ</span> | memo / note |
| Visitor name card A | <span lang="ja">ミナ</span> | Mina |
| Visitor name card B | <span lang="ja">ユミ</span> | Yumi |

**Reading evidence:** The role column tells you **what kind of label** each is. The katakana column tells you **exactly what is printed**. Katakana alone does not prove that a word names a product or a person. For example, <span lang="ja">ミナ</span> is a name *here* because it is on a visitor name card.

## Decode the shapes before interpreting

- <span lang="ja">ハム</span> is ハ (*ha*) + ム (*mu*). It is the food item, not a person's name in this display.
- <span lang="ja">バナナ</span> is バ (*ba*) + ナ (*na*) + ナ (*na*). バ has a voiced mark (dakuten) on ハ; this word is included as a familiar whole-word label, not a demand to master all voiced katakana yet.
- <span lang="ja">ヌノ</span> is ヌ (*nu*) + ノ (*no*). The scene uses phonetic katakana for a basic reading drill; real-world spelling varies.
- <span lang="ja">メモ</span> is メ (*me*) + モ (*mo*). Compare メ with ナ: their crossing strokes are not identical.
- <span lang="ja">ミナ</span> is ミ (*mi*) + ナ (*na*); <span lang="ja">ユミ</span> is ユ (*yu*) + ミ (*mi*). Read the first glyph carefully: ユ is not ヨ.

## Guided evidence practice

If someone asks, “Which visitor card starts with ユ?”, find the **visitor name-card rows** first, then inspect the katakana. The evidence is <span lang="ja">ユミ</span>, because its first character is ユ. If someone asks for the yellow fruit, find the **food shelf** and quote <span lang="ja">バナナ</span>. These examples model how to cite a printed label; the scored questions below use additional distinctions.

A common mistake is to treat every katakana word as a foreign product name. In this display the same script marks food, a note, and people. Another mistake is to infer spoken pronunciation from the printed cards: this exercise tests **reading**, not listening.

## Independent reading check

Answer eight questions using the display. Select one answer for each, then submit to reveal the evidence and explanations. Your score is local practice feedback, not a certified assessment. Completion is saved separately.

**Review:** Re-read the printed labels without the English column, then compare ナ/メ, ミ/ム and ユ/ヨ. The next lesson will use genuine recorded words for listening, not browser speech. Independent qualified Japanese and assessment reviews are pending.
