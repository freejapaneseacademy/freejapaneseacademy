## A note for the library desk

You have helped at a fictional library. A visitor wants to find a cat book. Your task is to **write**, not merely recognize, short connected hiragana sentences. You will type eight constrained answers and then compose your own two-line note. No romaji is needed in the finished Japanese.

### Step 1 — Observe and copy the building blocks

| Hiragana | Meaning | How it works |
| --- | --- | --- |
| <span lang="ja">ほん</span> | book | A noun |
| <span lang="ja">ねこ</span> | cat | A noun |
| <span lang="ja">ねこのほん</span> | book about cats | <span lang="ja">の</span> connects the nouns |
| <span lang="ja">としょかん</span> | library | Small <span lang="ja">ょ</span> in <span lang="ja">しょ</span> |
| <span lang="ja">となり</span> | next to | A location expression |
| <span lang="ja">あそこ</span> | over there | Away from both speakers |

Copy <span lang="ja">ねこのほん</span> once. Check that you used <span lang="ja">の</span>, not <span lang="ja">を</span>: the phrase describes **which book**, not an action.

### Step 2 — Build sentences

Start with the noun phrase <span lang="ja">ほん</span>. To say “I look at a book,” add the object particle <span lang="ja">を</span> and verb <span lang="ja">みます</span>:

**<span lang="ja">ほんをみます。</span>** — I look at a book.

For “Do you have a book?”, use the topic particle <span lang="ja">は</span>, existence verb <span lang="ja">あります</span>, and question particle <span lang="ja">か</span>:

**<span lang="ja">ほんはありますか。</span>** — Do you have a book?

In ordinary Japanese, words generally run together without teaching spaces. The particle <span lang="ja">は</span> is written **は** even though it is pronounced *wa* when marking a topic. <span lang="ja">を</span> is written **を** as the object particle. The full stop **。** closes both statements and questions in this beginner model; a question mark is not required.

Now expand the topic:

**<span lang="ja">ねこのほんはあそこです。</span>** — The cat book is over there.

Compare <span lang="ja">ねこのほんはあそこです。</span> (a location statement) with <span lang="ja">ねこのほんをみます。</span> (an action on a book). Swapping は and を changes the grammatical relationship; they are not interchangeable decorations.

### Step 3 — Type without looking

Hide the models above and answer eight writing prompts below. The first five ask for words or a noun phrase; the last three ask for complete sentences. Use your Japanese keyboard or IME to convert input into hiragana. The fixed-answer score compares the expected model after trimming outer whitespace and Unicode normalization; for these **constrained copying tasks**, retain the exact model punctuation and no internal spaces. It does not judge every possible natural Japanese sentence.

### Step 4 — Write your own note

Imagine a library desk sign for a visitor. Write **two short sentences** in hiragana. You may use the model below or substitute a familiar noun if your meaning remains clear:

**<span lang="ja">ねこのほんはあそこです。</span>**

**<span lang="ja">ほんをみます。</span>**

Use the optional editor after the scored practice. Compare your draft with the model and check four criteria: (1) recognizable hiragana and small kana, (2) a noun phrase with の where needed, (3) は for the topic and を for the object where applicable, and (4) sentence-final 。 and understandable meaning. The optional note is **learner self-review**, not automatically graded writing or teacher feedback. It remains in this browser tab and is not uploaded.

### Common corrections

- <span lang="ja">ねこをほん</span> does not mean “a cat book”; use <span lang="ja">ねこのほん</span>.
- <span lang="ja">ほんはみます。</span> can be grammatical in a contrastive context, but it is **not** the neutral object-marked model requested here: <span lang="ja">ほんをみます。</span>.
- Do not type Latin letters in the final answer. Use hiragana and include <span lang="ja">。</span> when the prompt asks for a sentence.
