## From recognizing a script to writing a useful label

Imagine helping a new classmate sort cards in a Japanese classroom. One card shows <span lang="ja">あ</span>, another shows <span lang="ja">ア</span>, and a third shows <span lang="ja"><ruby>山<rt>やま</rt></ruby></span>. You can already identify their scripts; now you will **write** a few symbols and **produce** short labels that help the classmate understand the difference. This is the writing/typing slot of the same chapter, not a new kana course.

**Today's Can-do:** create recognizable kana or a very short supported sentence to explain how **hiragana, katakana, kanji and romaji differ**. You will type actual Japanese characters, not merely select an English description. The Japanese sentences are deliberately short; your final four-script explanation may be in English because you have not yet learned the Japanese grammar needed to explain every distinction naturally.

You can use a Japanese keyboard, the complete on-screen character palette, or copy the models on paper. The palette is an accessibility alternative, **not evidence of independent IME fluency**. The open response is self-reviewed, not machine-graded. No microphone, new kanji recognition target or newly generated audio is required.

## 1. Notice what you are producing

Four kinds of marks appear in the classroom:

| Printed example | Role in the classroom | What you can produce today |
| --- | --- | --- |
| <span lang="ja">あ</span> / <span lang="ja">ア</span> | Hiragana and katakana forms of the same vowel *a* | Type each character with its correct script |
| <span lang="ja">さくら</span> | A familiar word in hiragana, meaning *cherry blossom* | Reproduce its three kana |
| <span lang="ja">コーヒー</span> | A katakana loanword meaning *coffee* | Reproduce the two length marks <span lang="ja">ー</span> |
| <span lang="ja"><ruby>山<rt>やま</rt></ruby></span> | Kanji with furigana showing the reading *yama* | Describe the relationship, not memorize the kanji |
| *sakura* | Romaji: a Japanese reading written in Latin letters | Explain that it is not the English meaning |

**Why the distinction matters:** *sakura* is not the English translation “cherry blossom”; it is a way to represent the Japanese word in Latin letters. Likewise, <span lang="ja">やま</span> above <span lang="ja">山</span> gives a Japanese **reading**. “Mountain” is its English **meaning**. A correct written explanation separates **script**, **reading** and **translation**.

## 2. Make the first five vowel forms

Review the vowel pairs from Lesson 04: <span lang="ja">あ/ア、い/イ、う/ウ、え/エ、お/オ</span>. Each pair represents the same vowel with a different written form. For example, if the teacher says “Write *a* in hiragana,” produce <span lang="ja">あ</span>, not <span lang="ja">ア</span> and not the Latin letter *a*.

**Guided routine:** look at <span lang="ja">あ</span> for three seconds, hide it, type the hiragana form, then compare the glyph. Repeat for katakana <span lang="ja">ア</span>. Try <span lang="ja">い</span> and <span lang="ja">オ</span> without looking. This tests character production, not sound discrimination; the actual narrated listening practice was in Lesson 06.

With a romaji-input Japanese IME, typing *a* while hiragana conversion is active typically produces <span lang="ja">あ</span>. Your device may use different conversion controls for katakana. Check the **final character** before submitting. If you cannot enable an IME, the interactive palette below contains all the characters needed for this lesson and lets you build words character by character.

## 3. Reproduce familiar words without changing their spelling

**Hiragana model:** <span lang="ja">さくら</span> (*sakura*) — cherry blossom. It has three characters: <span lang="ja">さ・く・ら</span>. When typing the word in this activity, do not substitute the Latin spelling *sakura*.

**Katakana model:** <span lang="ja">コーヒー</span> (*kōhī*) — coffee. It has four written characters: <span lang="ja">コ・ー・ヒ・ー</span>. The two <span lang="ja">ー</span> marks lengthen the vowels. Leaving them out changes the spelling, even if an English reader can guess the intended word.

**Script-name models:** <span lang="ja">ひらがな</span> (*hiragana*) is written in hiragana; <span lang="ja">カタカナ</span> (*katakana*) is written in katakana. The **name of a script** and the **script used to write that name** are different facts. You may also see the word <span lang="ja">かんじ</span> written in kana when talking about kanji; recognizing that label is not the same as learning a new kanji character.

**Common errors to catch:** replacing <span lang="ja">ア</span> with <span lang="ja">あ</span>, omitting a long-vowel mark from <span lang="ja">コーヒー</span>, or entering romaji instead of kana. The constrained writing check below treats these distinctions as meaningful; it only trims surrounding spaces and normalizes Unicode composition.

## 4. Build a tiny Japanese sentence

Point to a single card with <span lang="ja">あ</span>. A short classroom label can be:

<div class="foundation-example" role="group" aria-label="Japanese model label for hiragana">
  <p lang="ja">これはひらがなです。</p>
  <p>*Kore wa hiragana desu.* — “This is hiragana.” Here “this” refers to the written <span lang="ja">あ</span> card.</p>
</div>

Point instead to the card with <span lang="ja">ア</span>:

<div class="foundation-example" role="group" aria-label="Japanese model label for katakana">
  <p lang="ja">これはカタカナです。</p>
  <p>*Kore wa katakana desu.* — “This is katakana.” The referent has changed, so the script name changes too.</p>
</div>

The pieces are <span lang="ja">これ</span> (*kore*, this), the topic particle <span lang="ja">は</span> (pronounced *wa* in this use), a script name and polite <span lang="ja">です</span> (*desu*). Japanese normally has **no spaces between these parts**. This pattern identifies the script of the object you are pointing at; it does not mean that every word must always be written in that script.

Try the **guided label builder** below. Choose the correct script name for each printed card and check your two labels. Then type them yourself in the independent writing box. The builder gives formative feedback but does not save a grade.

## 5. Explain all four scripts in a supported note

You do **not** need an advanced Japanese sentence to explain the whole writing system yet. In English, aim for four short claims supported by examples:

- **Hiragana** writes many native Japanese word forms and grammatical endings; <span lang="ja">さくら</span> is our example.
- **Katakana** often writes loanwords and names for emphasis or classification; <span lang="ja">コーヒー</span> is a loanword example.
- **Kanji** are characters used in many Japanese words, often conveying meaning-related information; <span lang="ja">山</span> is a kanji, with <span lang="ja">やま</span> as its reading in our example.
- **Romaji** uses Latin letters to represent Japanese readings; *sakura* is a romanized Japanese word, not the English word *cherry blossom*.

These are **common uses**, not rules that every Japanese word has exactly one script. Japanese text often mixes scripts. You are describing **roles and examples**, not claiming that kanji have only one reading or that katakana can never write a Japanese-origin word.

## 6. Independent writing and revision

The interactive workshop has three stages. First, produce **eight constrained kana/word responses** and receive detailed feedback. Second, use a **guided two-card sentence builder** to check script names in <span lang="ja">これは…です。</span>. Third, independently type **two short Japanese labels** and an English explanation comparing all four scripts. Reveal a model only when ready and use the rubric to revise.

**Rubric for your independent response:** (1) readable kana in the correct script, (2) each label accurately identifies the card it points to, (3) all four script roles are distinguished with examples, and (4) reading/romaji are not confused with English meaning. These are learner-facing criteria, not a numerical proficiency score. Other accurate explanations and natural Japanese spacing/punctuation choices are welcome.

You may download your own draft as a text file or clear it. The open writing stays in this page's memory until you leave or refresh; it is **not** automatically saved to IndexedDB, transmitted, or included in your progress backup. The eight constrained answers produce only an aggregate score in the existing browser-local Dexie database. Marking the lesson complete is a separate choice.

## 7. Review: what can you now do?

A useful final test is to show someone <span lang="ja">あ</span>, <span lang="ja">ア</span>, <span lang="ja">山</span> and *sakura*, and explain what each representation does. Your Japanese labels can be as simple as <span lang="ja">これはひらがなです。</span> and <span lang="ja">これはカタカナです。</span>. For kanji and romaji, an accurate English explanation is appropriate at this stage.

If a character is hard to type, return to the five vowel pairs in Lesson 04. If the meaning-versus-reading distinction is unclear, revisit the evidence chart in Lesson 05. For real spoken pronunciation and hearing, replay the two recorded tracks in Lesson 06. **Next in the blueprint is Lesson 08: optional speaking and shadowing**; it is not part of this writing lesson.
