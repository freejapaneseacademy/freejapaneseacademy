## The reading-club sorting rule

Yui and Sora are sorting cards for the reading club. Some cards have two printed signs but **one rhythmic beat**. You already met words such as <span lang="ja">おちゃ</span> (tea), <span lang="ja">じしょ</span> (dictionary) and <span lang="ja">しゃしん</span> (photograph). Today you will explain *why* their small kana change the reading. This is written decoding practice; audio discrimination comes later in Lesson 06.

Japanese rhythm is often described using **morae**, not English syllables. In standard contracted combinations (拗音, *yōon*), an i-row kana combines with a **small** <span lang="ja">ゃ</span>, <span lang="ja">ゅ</span> or <span lang="ja">ょ</span>. Together they count as **one mora**. The small character is not an independent beat.

| First kana | + small ゃ | + small ゅ | + small ょ |
| --- | --- | --- | --- |
| <span lang="ja">き</span> | <span lang="ja">きゃ</span> (*kya*) | <span lang="ja">きゅ</span> (*kyu*) | <span lang="ja">きょ</span> (*kyo*) |
| <span lang="ja">し</span> | <span lang="ja">しゃ</span> (*sha*) | <span lang="ja">しゅ</span> (*shu*) | <span lang="ja">しょ</span> (*sho*) |
| <span lang="ja">ち</span> | <span lang="ja">ちゃ</span> (*cha*) | <span lang="ja">ちゅ</span> (*chu*) | <span lang="ja">ちょ</span> (*cho*) |
| <span lang="ja">に</span> | <span lang="ja">にゃ</span> (*nya*) | <span lang="ja">にゅ</span> (*nyu*) | <span lang="ja">にょ</span> (*nyo*) |
| <span lang="ja">り</span> | <span lang="ja">りゃ</span> (*rya*) | <span lang="ja">りゅ</span> (*ryu*) | <span lang="ja">りょ</span> (*ryo*) |

The same pattern also applies to familiar voiced i-row bases such as <span lang="ja">ぎ</span> → <span lang="ja">ぎゅ</span> (*gyu*), <span lang="ja">じ</span> → <span lang="ja">じゃ</span> (*ja*) and <span lang="ja">び</span> → <span lang="ja">びょ</span> (*byo*). This is a beginner chart, not a claim that every imaginable combination is a standard Japanese word.

## Small versus full-sized: meaning and timing

Compare the **written sequences** <span lang="ja">きゃ</span> (*kya*, one mora) and <span lang="ja">きや</span> (*ki-ya*, two morae). The second is a constructed decoding contrast, not a common standalone word. Likewise, <span lang="ja">しゅ</span> (*shu*) is one mora, while the constructed sequence <span lang="ja">しゆ</span> (*shi-yu*) has two. A full-sized <span lang="ja">や・ゆ・よ</span> remains a separate kana and mora. Do not read <span lang="ja">しゃ</span> as *shi-ya*.

Try the **cover-and-count** method: point at <span lang="ja">きゃ</span> and say “one beat”; point at <span lang="ja">きや</span> and say “two beats.” The visible character count is not the same as the mora count.

## Apply the pattern to real words

| Word | Break into morae | Meaning |
| --- | --- | --- |
| <span lang="ja">おちゃ</span> | <span lang="ja">お・ちゃ</span> (2) | tea |
| <span lang="ja">きゃく</span> | <span lang="ja">きゃ・く</span> (2) | guest |
| <span lang="ja">じしょ</span> | <span lang="ja">じ・しょ</span> (2) | dictionary |
| <span lang="ja">しゃしん</span> | <span lang="ja">しゃ・し・ん</span> (3) | photograph |
| <span lang="ja">しゅくだい</span> | <span lang="ja">しゅ・く・だ・い</span> (4) | homework |
| <span lang="ja">りょこう</span> | <span lang="ja">りょ・こ・う</span> (3) | trip |
| <span lang="ja">ぎゅうにゅう</span> | <span lang="ja">ぎゅ・う・にゅ・う</span> (4) | milk |
| <span lang="ja">びょういん</span> | <span lang="ja">びょ・う・い・ん</span> (4) | hospital |

**Important nuance:** A contracted pair counts as one mora, but a following long-vowel kana such as <span lang="ja">う</span> still counts as another mora. For example, <span lang="ja">きょう</span> is <span lang="ja">きょ・う</span> (two morae), not one. Likewise, <span lang="ja">ぎゅうにゅう</span> has two blended pairs **and** two additional <span lang="ja">う</span> morae. Written practice cannot establish accurate pronunciation; use the real listening lesson when it becomes available.

## The rule in a classroom exchange

Yui says <span lang="ja">しゃしんをみてください。</span> — “Please look at the photograph.” Sora replies <span lang="ja">しゃしんですね。</span> — “The photograph, right.” Here <span lang="ja">しゃ</span> belongs to the noun <span lang="ja">しゃしん</span>; the polite request <span lang="ja">みてください</span> does not change the contracted-kana rule. The particle <span lang="ja">を</span> marks the object. The expression <span lang="ja">ですね</span> checks or confirms shared understanding.

**Controlled practice:** Underline the small kana in <span lang="ja">おちゃ</span>, <span lang="ja">じしょ</span> and <span lang="ja">りょこう</span>. **Guided practice:** Count the morae in <span lang="ja">しゃしん</span> and <span lang="ja">きょう</span>, then compare your counts with the table. **Independent practice:** Without the table, explain why <span lang="ja">きゃ</span> and <span lang="ja">きや</span> differ, and why <span lang="ja">ぎゅうにゅう</span> is not two morae.
