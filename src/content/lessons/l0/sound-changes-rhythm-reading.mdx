## Read a classroom picture-board

Two learners, Aki and Yui, are preparing a small exhibition. Each picture has a short Japanese caption and a numbered label. Read the **eight original captions** below as your source. You do not need audio, a dictionary or prior kanji knowledge: English context notes identify unfamiliar words. Your job is to **find explicit information and quote the Japanese that proves it**.

**Today's Can-do:** recognize long vowels, small <span lang="ja">っ</span> and nasal <span lang="ja">ん</span> in meaningful written captions, and answer a reading question with the precise supporting words. This is reading comprehension, not a hearing or pronunciation test.

## The exhibition caption board

| Card | Printed Japanese caption | Context note |
| --- | --- | --- |
| A · Family | <span lang="ja">これは おばあさん の しゃしん です。</span> | This is a photograph of a grandmother. |
| B · Family | <span lang="ja">これは おばさん の しゃしん です。</span> | This is a photograph of an aunt. |
| C · People | <span lang="ja">さっか は ほん を かきます。</span> | A writer writes a book. |
| D · Outdoors | <span lang="ja">この さか は ながい です。</span> | This slope is long. |
| E · Mail | <span lang="ja">きって は ここ に あります。</span> | The postage stamp is here. |
| F · Movement | <span lang="ja">ここ に きて ください。</span> | Please come here. |
| G · School | <span lang="ja">こうこう の せんせい です。</span> | (This person) is a high-school teacher. |
| H · Walk | <span lang="ja">さんぽ の あとで ほん を よみます。</span> | After a walk, (someone) reads a book. |

These are simplified, beginner-friendly written captions. Spaces separate learning chunks; ordinary Japanese writing often omits them. A context note translates the whole caption rather than claiming a one-to-one match between every English and Japanese word. The subject is omitted where Japanese allows it; do not invent a named person.

## 1. Scan for a word, then read its neighbors

Aki asks which card shows a **grandmother**. Scan Cards A and B. Both include <span lang="ja">しゃしん</span> (“photograph”), but Card **A** prints <span lang="ja">おばあさん</span>, while B prints <span lang="ja">おばさん</span>. The extra <span lang="ja">あ</span> matters. A complete evidence answer is: “**Card A — おばあさん**,” not just “A.”

The conventional written mora divisions are <span lang="ja">お・ば・あ・さ・ん</span> (five) and <span lang="ja">お・ば・さ・ん</span> (four). The <span lang="ja">ん</span> is one mora in both words. The additional vowel mora distinguishes the family labels in this exhibition.

**Guided question:** Which card labels an aunt? **B**. Evidence: <span lang="ja">おばさん</span>. Do not cite <span lang="ja">しゃしん</span>, because that only means photograph and appears on both cards.

## 2. A small kana changes the caption

Cards C and D are deliberately easy to confuse at a glance. Card C prints <span lang="ja">さっか</span> (“writer”); Card D prints <span lang="ja">さか</span> (“slope”). The small <span lang="ja">っ</span> occupies a mora in <span lang="ja">さ・っ・か</span> and is **not** the same as full-size <span lang="ja">つ</span>. Card C also has <span lang="ja">ほん</span> (“book”), confirming the writer scene.

Card E prints <span lang="ja">きって</span> (“postage stamp”), while Card F prints <span lang="ja">きて</span> (“come,” in a request). The small <span lang="ja">っ</span> is the visible distinction. Card F includes <span lang="ja">ください</span>, a polite request expression, so its whole sentence is “Please come here.” Do not claim that <span lang="ja">きて</span> means “stamp.”

**Guided question:** Which card is a polite request? **F**. Evidence: <span lang="ja">きて ください</span>. The word <span lang="ja">ください</span> supports the request reading; merely spotting the letter <span lang="ja">て</span> would not.

## 3. Two more ways to count written rhythm

Card G contains <span lang="ja">こうこう</span> (“high school”), conventionally written <span lang="ja">こ・う・こ・う</span>: four morae. Many Japanese long *o* vowels use <span lang="ja">う</span> in hiragana spelling. Do not rewrite this word as <span lang="ja">こおこお</span> by mechanically doubling the same kana.

Card H contains <span lang="ja">さんぽ</span> (“walk”), written <span lang="ja">さ・ん・ぽ</span>: three morae. It also contains <span lang="ja">ほん</span> (“book”), <span lang="ja">ほ・ん</span>: two morae. The nasal <span lang="ja">ん</span> counts even though it does not have a following vowel. Its actual articulation changes with context, but this printed board cannot demonstrate that sound.

**Guided question:** Which card says that someone reads a book after a walk? **H**. Evidence: <span lang="ja">さんぽ の あとで ほん を よみます</span>. This is a sentence-level clue, not just an isolated sound symbol.

## 4. How to cite a reading answer

For each question, give **(1) the card letter and (2) the shortest Japanese phrase that proves the answer**. A good answer to “Where is the stamp?” is “**E — きって は ここ に あります**.” The phrase states that the stamp is here. Quoting only <span lang="ja">ここ</span> (“here”) would not identify what is here.

A plausible wrong answer is not evidence. For example, Card F also has <span lang="ja">ここ</span>, but it is a request to come here, not a statement that a stamp is here. Read the complete caption and its function.

## 5. Common reading errors

**Skipping a small character.** <span lang="ja">さっか</span> is not <span lang="ja">さか</span>; <span lang="ja">きって</span> is not <span lang="ja">きて</span>. Zoom in and compare the printed kana before choosing.

**Treating every long vowel as repeated identical kana.** The spelling <span lang="ja">こうこう</span> includes <span lang="ja">う</span>. Count <span lang="ja">こ・う・こ・う</span>, not the letters in *kōkō*.

**Dropping ん when counting.** <span lang="ja">さんぽ</span> has three morae; <span lang="ja">ほん</span> has two. The nasal is its own unit.

**Answering from English alone.** The context notes help, but the scored questions ask you to locate Japanese evidence. Cite a Japanese word or phrase, not only an English translation.

**Claiming the board proves hearing.** Printed words cannot establish that you heard a long vowel, consonant hold or nasal. Chapter 03 L06 will require real playable recordings and blind listening questions.

## 7. Independent writing extension

Cover the context notes. In English, write two short evidence statements: one contrasting Cards A and B and another contrasting Cards C and D. Include the Japanese words in each comparison. Compare with this model:

- “A is grandmother: <span lang="ja">おばあさん</span>; B is aunt: <span lang="ja">おばさん</span>. A contains the extra <span lang="ja">あ</span>.”
- “C is writer: <span lang="ja">さっか</span>; D is slope: <span lang="ja">さか</span>. C contains small <span lang="ja">っ</span>.”

Self-check: did you quote the exact printed words, identify the right card and explain the visible difference? This writing extension is self-reviewed, not automatically graded.
