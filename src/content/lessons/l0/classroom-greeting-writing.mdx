## Can-do: write a two-line classroom note

Imagine that you are leaving a note for a teacher or classmate. Write a greeting on the first line and a clear request on the second. This is **writing** practice: a written note is not a listening or pronunciation assessment.

## 1. Choose a greeting

| Situation | Japanese | Meaning |
| --- | --- | --- |
| Morning, to a teacher | おはようございます。 | Good morning (polite). |
| Morning, to a friend | おはよう。 | Morning! |
| Daytime | こんにちは。 | Hello. |
| After receiving help | ありがとうございます。 | Thank you very much. |

The final **は** in こんにちは is pronounced *wa*, but the standard spelling is **は**, not わ. The additional ございます makes the morning greeting polite. Thanks is a response to help, not a substitute for a greeting.

## 2. Choose a request

| Japanese | Meaning |
| --- | --- |
| みてください。 | Please look. |
| きいてください。 | Please listen. |
| よんでください。 | Please read. |
| かいてください。 | Please write. |
| もういちど いってください。 | Please say it again. |

Do not confuse **きいてください** (listen) with **きてください** (come). The extra い matters. **よんで** needs voiced で, and **いって** needs small っ.

## 3. Read an original model

A student leaves a morning note for the teacher:

> おはようございます。  
> このカードを みてください。

“Good morning. Please look at this card.” The first line suits a teacher. **このカード** is “this card,” and **を** marks the object. You may use the simpler **みてください。** without the object if you have not yet studied を.

Another original note for a classmate after lunch:

> こんにちは。  
> よんでください。

“Hello. Please read.” The reader needs a visible card or page for this short request to be clear.

## 4. Write, compare and revise

1. Decide the recipient and time of day.
2. Type a greeting on line one.
3. Type one classroom request on line two. You may add このカードを before みてください or よんでください.
4. Compare with the models above. The exact words may differ; a fitting greeting and understandable request are the goal.
5. Review using four criteria: **appropriate greeting**, **accurate kana**, **clear request**, **polite tone**.

### Guided revision

If you wrote **こんにちわ**, correct it to **こんにちは**. If you wrote **きてください** intending “please listen,” change it to **きいてください**. If you wrote **よんてください**, add the dakuten to make **よんでください**.

### Independent challenge

Write a daytime greeting to a classmate asking them to read a card. Then write a morning note to a teacher asking them to look at the card. Compare both with the model and check all four criteria. No software can automatically certify your free writing here; you make the rubric judgment.
