## Copy a message at the library desk

**Chapter Can-do:** Decode short hiragana sentences without relying on romaji. Yui has found the picture books; now she wants to write a short note about what she sees. You will recognize, type and optionally trace the kana and punctuation in the library conversation. This is **written practice**, not a listening, speaking or handwriting-certification assessment.

Japanese normally writes these sentences without spaces between words. The spaced versions below are **temporary beginner guides**, not a different spelling system.

| Guided chunks | Ordinary connected writing | Meaning |
| --- | --- | --- |
| <span lang="ja">えほんは ありますか。</span> | <span lang="ja">えほんはありますか。</span> | Do you have picture books? |
| <span lang="ja">はい、あります。</span> | <span lang="ja">はい、あります。</span> | Yes, we do. |
| <span lang="ja">えほんは ここです。</span> | <span lang="ja">えほんはここです。</span> | The picture books are here. |
| <span lang="ja">えほんを みます。</span> | <span lang="ja">えほんをみます。</span> | I'll look at picture books. |

## Look closely at the written forms

The characters <span lang="ja">は</span> and <span lang="ja">を</span> are **different kana**. In <span lang="ja">えほんはここです。</span>, は follows the topic えほん; as a topic particle it is pronounced *wa* but **written は**, never わ in this pattern. In <span lang="ja">えほんをみます。</span>, を marks the object of the action みます. Do not swap the two just because both are short particles.

In <span lang="ja">えほんはありますか。</span>, the **か** is immediately before the final <span lang="ja">。</span>. It turns this polite availability statement into a question. The mark <span lang="ja">。</span> closes the sentence, while <span lang="ja">、</span> separates the opening acknowledgment in <span lang="ja">はい、あります。</span>. A comma is not the same character as a full stop.

### Trace the parts before writing the whole

Read each string from left to right and count the kana. <span lang="ja">え・ほ・ん</span> makes えほん (picture book); <span lang="ja">こ・こ</span> makes ここ (here); <span lang="ja">み・ま・す</span> makes みます (look at). The kana <span lang="ja">ん</span> is a separate mora; it is not the same as <span lang="ja">ま</span>. Copy the words once, then cover the models and reconstruct them. This lesson assesses **written recognition**, not the sound of an unseen recording.

## A three-stage writing ladder

**1. Observe:** Point to the topic particle in <span lang="ja">えほんはここです。</span> and to the object particle in <span lang="ja">えほんをみます。</span>. Find the final question particle in <span lang="ja">えほんはありますか。</span>.

**2. Recombine:** Write <span lang="ja">えほん</span> + <span lang="ja">を</span> + <span lang="ja">みます</span> + <span lang="ja">。</span> as one connected sentence: <span lang="ja">えほんをみます。</span>. Then write <span lang="ja">えほん</span> + <span lang="ja">は</span> + <span lang="ja">ここです</span> + <span lang="ja">。</span>. Keep the same order and omit teaching spaces.

**3. Independent:** Without looking, type <span lang="ja">えほんはありますか。</span> and <span lang="ja">はい、あります。</span>. Use a Japanese IME; inspect the resulting kana rather than trusting an English-keyboard sequence. If you cannot use an IME, write the sentence on paper and use the recognition quiz below as your accessible alternative.

## Optional tracing and self-review

On paper, copy <span lang="ja">は・を・か・ん</span> and then <span lang="ja">えほんはここです。</span>. Trace only from a reliable writing reference you already have; this activity does **not** claim to demonstrate authoritative stroke order. Compare your work with the printed model using four criteria: (1) each kana has the same shape; (2) は and を have not been exchanged; (3) the characters appear in the correct sequence; (4) 、 and 。 are placed correctly. Your own comparison is **ungraded**; no photo or handwriting data is uploaded.

### Common mix-ups

Writing <span lang="ja">えほんわここです。</span> is a common beginner mistake: the topic particle is **は**, even though it is pronounced *wa*. Writing <span lang="ja">えほんはみます。</span> instead of <span lang="ja">えほんをみます。</span> changes the grammatical focus and does not express the same neutral object-marked example. And <span lang="ja">はい。あります。</span> is two sentences rather than the one comma-separated reply shown here; preserve the model when copying.
