## Write a short personal-details card

**Can-do:** State and recognize basic numbers, names and nationalities. This is the writing and typing step: create a recognizable supported sentence or form entry, then compare it with a model and a criteria-based rubric. No real personal data is needed: use the fictional learner ミナ (Mina) or your own invented character.

### The model card

| Field | Japanese model | Meaning |
| --- | --- | --- |
| なまえ (name) | <span lang="ja">ミナ</span> | Mina |
| くに (country) | <span lang="ja">カナダ</span> | Canada |
| こくせき (nationality) | <span lang="ja">カナダじん</span> | Canadian |
| ばんごう (number) | <span lang="ja">二十四</span> | 24 |

These are **fictional practice details**. A country is not the same as a nationality: カナダ means Canada, while カナダじん means a Canadian person. The suffix <span lang="ja">じん</span> attaches to many country names, but not every real-world nationality is formed without nuance.

## Build the statement, one piece at a time

1. <span lang="ja">わたし</span> means *I*. The topic particle <span lang="ja">は</span> is **written は but pronounced wa**.
2. Insert the name: <span lang="ja">わたしは ミナです。</span> — *I am Mina.* The polite <span lang="ja">です</span> finishes a statement; do not replace it with question-marking <span lang="ja">か</span>.
3. For a country of origin, use <span lang="ja">わたしは カナダから きました。</span> — *I came from Canada.* Here <span lang="ja">から</span> marks the starting point. This describes origin, not necessarily citizenship.
4. For nationality, use <span lang="ja">わたしは カナダじんです。</span> — *I am Canadian.* The country and nationality statements are different claims.

In a name field, **ミナ** is enough. In a complete sentence, write <span lang="ja">わたしは ミナです。</span>. A field label is not a sentence, and you need not add です to every form field.

## Number-writing toolkit: 0–100

| Value | Written form | Reading |
| --- | --- | --- |
| 0 | <span lang="ja">零 / ゼロ</span> | rei / zero |
| 4 | <span lang="ja">四</span> | yon / shi |
| 10 | <span lang="ja">十</span> | juu |
| 20 | <span lang="ja">二十</span> | nijuu |
| 24 | <span lang="ja">二十四</span> | nijuuyon |
| 36 | <span lang="ja">三十六</span> | sanjuuroku |
| 48 | <span lang="ja">四十八</span> | yonjuuhachi |
| 100 | <span lang="ja">百</span> | hyaku |

Write tens before ones: <span lang="ja">四十八</span> = 四十 (40) + 八 (8), **not** 八十四 (84). Zero may appear as 0 or ゼロ on modern forms. Ages have additional conventions: 20 years old is often <span lang="ja">はたち</span>, not simply にじゅうさい.

## Guided copying and meaningful composition

First copy <span lang="ja">ミナ</span>, <span lang="ja">カナダ</span>, <span lang="ja">二十四</span> and <span lang="ja">わたしは ミナです。</span> by hand or in a Japanese IME. Pay attention to kana size and the direction of each stroke if handwriting. For typing, enter phonetic readings and select the intended kanji conversion rather than accepting the first candidate blindly.

Then compose an **original fictional** card with a different name, country and number. Suggested safe character: ユミ, from 日本 (にほん), number 36. Model: <span lang="ja">わたしは ユミです。わたしは にほんから きました。</span> A nationality sentence would be <span lang="ja">わたしは にほんじんです。</span>. You may write 日本人 as the conventional kanji spelling when ready.

### Check your own writing

Use the typing studio below to compare each field with its **specific model**, or write a different fictional character and use the checklist without automatic scoring. The strict model comparison is only a typing aid: it does not grade handwriting, meaning, or personal identity.

- **Meaning:** Does each field contain the requested name, country, nationality or number?
- **Form:** Are the kana, small characters, and kanji conversion legible and in the right order?
- **Grammar:** Does a full polite statement include は (topic) and です? Is か reserved for questions?
- **Re-read:** Can you read what you wrote and explain the difference between くに and こくせき?
