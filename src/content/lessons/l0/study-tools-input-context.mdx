## At the computer-study table

**Chapter Can-do:** Enter Japanese using a keyboard and control reading aids. In this first lesson, identify who needs help, what they are trying to do, and why the tools matter. You do not need to memorize keyboard shortcuts or master an entire input method yet.

At a study table, learner **Aya** is writing a label for a picture. Tutor **Ken** shows her how to switch to Japanese input and how to use a reading aid when an unfamiliar written word appears. The exchange below is original written instruction, **not recorded audio**.

| Speaker | Japanese | Meaning |
| --- | --- | --- |
| Aya | <span lang="ja">すみません。</span> | Excuse me. (Polite attention-getter.) |
| Aya | <span lang="ja">にほんごで かきたいです。</span> | I want to write in Japanese. |
| Ken | <span lang="ja">にほんごの にゅうりょくに してください。</span> | Please switch to Japanese input. |
| Aya | <span lang="ja">「ねこ」と かけました。</span> | I managed to write “ねこ.” |
| Ken | <span lang="ja">いいですね。</span> | That's good. |

The spaces are beginner reading supports. In ordinary Japanese writing, words are generally not separated by spaces. The short dialogue models a learning situation rather than a universal keyboard instruction: actual menu names differ across devices.

## 1. A keyboard does not need Japanese key labels

An **IME** (input method editor) converts typed input into Japanese text. Depending on the device and settings, you may type Latin letters such as `neko` and receive <span lang="ja">ねこ</span>. This is **romaji input**, a typing method, not a claim that Japanese is normally written in romaji.

| Intended word | One common romaji-input sequence | Kana output | Meaning |
| --- | --- | --- | --- |
| cat | `neko` | <span lang="ja">ねこ</span> | cat |
| school | `gakkou` | <span lang="ja">がっこう</span> | school |
| Japanese language | `nihongo` | <span lang="ja">にほんご</span> | Japanese language |

These examples assume a standard romaji-input configuration. Input modes, conversion behavior and keystrokes vary. The double **kk** in `gakkou` produces the small <span lang="ja">っ</span> in common romaji input, while <span lang="ja">がっこう</span> also contains a long vowel written <span lang="ja">こう</span>.

**Controlled practice:** Which output would Aya want for a picture of a cat? <span lang="ja">ねこ</span>, not the literal Latin letters `neko`, when the goal is a Japanese kana label.

## 2. Furigana helps you read; it does not change the word

**Furigana** are small reading characters placed near kanji. For example, <ruby lang="ja">日本語<rt>にほんご</rt></ruby> has a reading aid above the written word. The word itself is still <span lang="ja">日本語</span>; the aid tells you how to read it. At Level 0, recognizing this distinction is enough. You are **not** being tested on writing these kanji.

If you turn reading aids off, the main word remains. If you switch Japanese keyboard input off, you may be unable to type kana directly with the same keystrokes. These are **different controls**.

**Guided check:** Aya sees <ruby lang="ja">日本語<rt>にほんご</rt></ruby>. What does <span lang="ja">にほんご</span> above the kanji do? It shows the reading; it is not a translation or a replacement for the written word.

## 3. Ask for help politely

<span lang="ja">すみません。</span> is a common polite way to get someone's attention. In a classroom, Aya can say:

- <span lang="ja">すみません。おねがいします。</span> — Excuse me. Please. (Context supplies the request.)
- <span lang="ja">もういちど おねがいします。</span> — One more time, please.
- <span lang="ja">ゆっくり おねがいします。</span> — Slowly, please.

These are useful support phrases, but they are not all-purpose translations for every English request. For a precise keyboard instruction, add context or name the task.

## 4. Follow the purpose, not just the letters

Ken's role is to guide Aya's input settings. Aya's goal is to **produce Japanese kana for a meaningful label**, not merely to copy a Latin spelling. A reading aid supports comprehension of a displayed word; it does not type the word for her.

**Independent use:** Imagine you have a picture of a cat and a device set to Latin-letter input. Explain in English which setting you would look for, what you would type under a common romaji-input configuration, and what Japanese text you expect to see. Then identify one polite phrase you could use if you need the tutor to repeat the instructions.

**Model:** “I would enable Japanese input, type `neko` with romaji input, and check that <span lang="ja">ねこ</span> appears. If I miss the instruction, I can say <span lang="ja">もういちど おねがいします。</span>”

## Common mistakes

**Typing `neko` is not always the same as producing <span lang="ja">ねこ</span>.** If the IME is off, the letters may stay Latin. **Furigana is not a keyboard layout.** It helps you read an existing word. **Kanji conversion is not required for every beginner task.** For this lesson, a correct kana label is sufficient.
