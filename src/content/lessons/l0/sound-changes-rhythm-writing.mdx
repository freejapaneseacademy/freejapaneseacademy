## Your mission: make labels that another learner can understand

A small Japanese-language exhibition needs captions for six pictures. The pictures show a **grandmother**, an **aunt**, a **writer**, a **slope**, a **postage stamp**, and a **book**. You will write the labels, then a tiny request and a sentence. These are fictional classroom situations; do not enter personal information.

**Today's Can-do:** write short, recognizable Japanese using long vowels, small <span lang="ja">っ</span> and nasal <span lang="ja">ん</span>. A spelling change can change which person or object a reader understands. The goal is **writing**, not guessing how an unheard recording sounds.

## 1. See how the three rhythm markers work

A *mora* is a Japanese timing unit. A basic kana such as <span lang="ja">か</span> is usually one mora. The second unit of a long vowel, small <span lang="ja">っ</span> and nasal <span lang="ja">ん</span> also count as one each.

| What you want to say | Correct kana | Mora count | What to notice |
| --- | --- | --- | --- |
| aunt | <span lang="ja">おばさん</span> | お・ば・さ・ん = 4 | No extra あ |
| grandmother | <span lang="ja">おばあさん</span> | お・ば・あ・さ・ん = 5 | Extra あ lengthens the vowel |
| slope | <span lang="ja">さか</span> | さ・か = 2 | No small っ |
| writer | <span lang="ja">さっか</span> | さ・っ・か = 3 | Small っ before か |
| postage stamp | <span lang="ja">きって</span> | き・っ・て = 3 | Small っ before て |
| book | <span lang="ja">ほん</span> | ほ・ん = 2 | ん is its own mora |

The written long *o* in <span lang="ja">こうこう</span> (high school) is conventionally こ・う・こ・う, four morae. Do not invent the spelling <span lang="ja">こおこお</span>. In katakana, <span lang="ja">コーヒー</span> (coffee) uses the length mark ー twice.

## 2. Observe a complete caption

**Model:** <span lang="ja">これは おばあさん の しゃしん です。</span> — “This is a photograph of a grandmother.”

Here <span lang="ja">これは</span> introduces the topic; <span lang="ja">の</span> links “grandmother” to “photograph”; <span lang="ja">です</span> ends the polite statement. The spaces are beginner reading aids, not standard punctuation. Replace <span lang="ja">おばあさん</span> with <span lang="ja">おばさん</span> and the caption now refers to an **aunt**. Both sentences are grammatical, but only one matches the intended picture.

**Guided rewrite:** For an aunt photograph, write <span lang="ja">これは おばさん の しゃしん です。</span> Compare the two versions character by character. A spellchecker cannot know which picture you meant.

## 3. Build a polite request

**Model:** <span lang="ja">きって を にまい ください。</span> — “Two postage stamps, please.” The written noun <span lang="ja">きって</span> includes small っ. In contrast, <span lang="ja">ここ に きて ください。</span> means “Please come here”; <span lang="ja">きて</span> is the te-form of “come,” without small っ. Both use <span lang="ja">ください</span> but ask for different things.

For this supported writing task, copy the full model before changing a word. Do not assume that every expression with <span lang="ja">ください</span> has the same grammar: <span lang="ja">きって を にまい ください</span> requests a noun, while <span lang="ja">きて ください</span> requests an action.

## 4. Put nasal ん in a meaningful sentence

**Model:** <span lang="ja">さんぽ の あとで ほん を よみます。</span> — “After a walk, (someone) reads a book.”

In <span lang="ja">さんぽ</span>, count さ・ん・ぽ; in <span lang="ja">ほん</span>, count ほ・ん. The subject is omitted; Japanese often allows that when context is clear. Do not invent a named subject from this sentence. The exact pronunciation of ん changes with its neighbors, but its written form remains ん.

**Guided rewrite:** “The book is here” → <span lang="ja">ほん は ここ に あります。</span> This is a useful location statement for the exhibition. It is not the same as <span lang="ja">ここ に きて ください</span>, a request to come here.

## 5. Type, compare and revise

Use the interactive writing studio below. First complete constrained kana labels, then write a supported caption or request. A Japanese keyboard/IME is recommended. Input methods differ by device: inspect the actual converted **kana**, especially the small っ and ん. A visible romaji string is not the finished Japanese spelling.

The studio checks exact kana for the short constrained labels. For longer sentences, **you** compare your draft against the model and use the checklist. A different natural sentence may also be valid; the site does not pretend to grade open-ended Japanese or handwriting.

### Self-review rubric for the two longer messages

- **Meaning:** Does the sentence identify the intended person/object or make the intended request?
- **Script:** Are the required long-vowel kana, small っ and ん present in the right places?
- **Sentence function:** Does a label use <span lang="ja">これは … です</span> appropriately, or does a request use <span lang="ja">ください</span>?
- **Readability:** Can you read the final kana back without relying on romaji? Spaces may be kept as learning aids.

A self-check is a practice reflection, **not** an independent teacher assessment or a pronunciation score.

## 6. Common mistakes to repair

**Leaving out one vowel:** <span lang="ja">おばさん</span> means aunt, not grandmother. Add あ to write <span lang="ja">おばあさん</span>.

**Using full-size つ:** <span lang="ja">さつか</span> is not the target <span lang="ja">さっか</span>. The small っ marks the held consonant interval and takes one mora.

**Dropping nasal ん:** <span lang="ja">ほ</span> is just a kana/sound label here, not the word <span lang="ja">ほん</span> (book). Similarly, <span lang="ja">さんぽ</span> requires ん.

**Copying a word without its context:** <span lang="ja">きって</span> (stamp) and <span lang="ja">きて</span> (come) differ in spelling **and grammatical role**. Read the entire sentence before submitting.

## 7. Independent practice

Cover the models. Write a caption for a grandmother photograph, a request for two stamps and a sentence about a book being here. Then uncover the models and revise your drafts.
