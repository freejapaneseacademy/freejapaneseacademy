## Your final kana workshop

A classmate has made a few small spelling mistakes while preparing for N5. You will help correct them by **noticing the exact character**, not by guessing from the English meaning. This is a written script lesson; it does not test your listening or pronunciation. Allow about 20–25 minutes and revisit weak forms tomorrow.

## 1. Start with the script, not the translation

Hiragana and katakana can represent the same sound. **さ** and **サ** both represent *sa*, but their shapes and typical contexts differ. Hiragana is common in native words and grammatical endings; katakana often appears in loanwords, names and emphasis. The scripts are not interchangeable in ordinary spelling.

| Sound cue | Hiragana | Katakana | Noticing task |
| --- | --- | --- | --- |
| sa | <span lang="ja">さ</span> | <span lang="ja">サ</span> | Compare the curved and angular strokes |
| ki | <span lang="ja">き</span> | <span lang="ja">キ</span> | Both have crossing strokes; identify the script first |
| se | <span lang="ja">せ</span> | <span lang="ja">セ</span> | Look for the rounded hiragana ending |
| n | <span lang="ja">ん</span> | <span lang="ja">ン</span> | Compare <span lang="ja">ン</span> with katakana <span lang="ja">ソ</span>; the stroke directions differ |

A familiar word: <span lang="ja">さくら</span> (*sakura*, cherry blossom) is normally written here in hiragana, not <span lang="ja">サクラ</span> for this exercise. Katakana サクラ is possible in particular stylistic or naming contexts, so the point is **conventional usage**, not that a sound belongs to only one script.

## 2. Small っ and ッ: one tiny mark changes a word

Compare <span lang="ja">きって</span> (*kitte*, postage stamp) with <span lang="ja">きて</span> (*kite*, a form of “come”). The first contains **small っ** immediately before て. It marks a held consonant; do not replace it with a full-sized つ.

In katakana, <span lang="ja">チケット</span> (*chiketto*, ticket) contains **small ッ**. <span lang="ja">チケト</span> omits that marker and is not the conventional spelling.

Another review word is <span lang="ja">がっこう</span> (*gakkō*, school). Break it into written units: **が・っ・こ・う**. The っ belongs before こ; the う represents the long *o* vowel in this word. A useful correction note is: “I omitted small っ,” not simply “I got the word wrong.”

## 3. Small ゃ and the long-vowel mark

<span lang="ja">きゃ</span> (*kya*) combines き with **small ゃ**. <span lang="ja">きや</span> (*kiya*) uses a full-sized や and represents a different sequence. Compare the size of the second character before reading.

Katakana commonly uses **ー** to write a long vowel in loanwords. <span lang="ja">コーヒー</span> (*kōhī*, coffee) has two ー marks. <span lang="ja">カメラ</span> (*kamera*, camera) has none. Do not insert ー merely because an English word sounds long.

Hiragana long vowels can use an extra vowel kana: <span lang="ja">おばさん</span> (*obasan*, aunt or middle-aged woman depending on context) and <span lang="ja">おばあさん</span> (*obaasan*, grandmother or elderly woman) are different words. Here the extra **あ** matters.

## 4. Guided correction lab

Read the following fictional notebook entries. Each arrow shows the **intended** form, not a claim that the first form is a standard Japanese word.

| Learner wrote | Intended form | What to notice |
| --- | --- | --- |
| <span lang="ja">がこう</span> | <span lang="ja">がっこう</span> | Missing small っ |
| <span lang="ja">チケト</span> | <span lang="ja">チケット</span> | Missing small ッ |
| <span lang="ja">コヒ</span> | <span lang="ja">コーヒー</span> | Missing long-vowel marks |
| <span lang="ja">きや</span> | <span lang="ja">きゃ</span> | Full-sized や instead of small ゃ |

Try this process: **look → cover → type → compare → name the error → retry**. Read the model once, hide it, type from memory, then check each kana. A successful copy with the model visible is not the same as independent recall.

## 5. Independent typing studio

Use the ungraded typing fields below. Type **がっこう**, **チケット**, **コーヒー** and **きゃ** with your Japanese IME, then reveal each model. If you cannot use an IME, copy the forms by hand and compare them visually. Handwriting is optional. The studio accepts and compares Unicode text locally; it does not grade handwriting or speech.

For a common desktop Japanese IME, typing *gakkou* typically yields がっこう and *kya* yields きゃ; conversion behavior depends on the IME. Check the actual displayed kana rather than trusting the Latin input sequence.

## 6. Retrieval and tomorrow's plan

Complete the ten written checks, then choose **two forms you missed**. Make a private note naming the exact issue (for example, “small ッ in チケット”). Recheck those forms after a break or on your next study day without looking first. If you got everything correct, choose two forms to retrieve after a delay. This is a sustainable study suggestion, not a claim of certified fluency or JLPT readiness.
