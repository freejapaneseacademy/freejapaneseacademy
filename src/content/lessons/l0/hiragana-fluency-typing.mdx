## The classroom word-card shelf

Hana has ten printed labels for classroom picture cards. Each label is written in **basic hiragana**. First read the Japanese word, then check the meaning and reading. The romanization is a temporary aid; the independent activity asks for **hiragana**, not Latin letters.

| Printed label | Meaning | Reading |
| --- | --- | --- |
| <span lang="ja">ねこ</span> | cat | neko |
| <span lang="ja">いぬ</span> | dog | inu |
| <span lang="ja">くるま</span> | car | kuruma |
| <span lang="ja">やま</span> | mountain | yama |
| <span lang="ja">ほん</span> | book | hon |
| <span lang="ja">はな</span> | flower | hana |
| <span lang="ja">そら</span> | sky | sora |
| <span lang="ja">みみ</span> | ear | mimi |
| <span lang="ja">ゆき</span> | snow | yuki |
| <span lang="ja">かわ</span> | river | kawa |

The labels are isolated **nouns**, not complete sentences. The word <span lang="ja">はな</span> can mean *flower* or *nose* depending on context; on this picture card it means **flower**. <span lang="ja">ほん</span> contains <span lang="ja">ん</span>, an independent mora, and is written with two kana.

### Check the whole shape

Compare <span lang="ja">ね / れ</span>, <span lang="ja">ぬ / め</span>, and <span lang="ja">る / ろ</span>. The loop at the end of <span lang="ja">ね</span>, <span lang="ja">ぬ</span>, or <span lang="ja">る</span> can help in these particular printed forms. Fonts vary: identify the **complete character**, not just one stroke.

Read <span lang="ja">ねこ</span> as two kana, <span lang="ja">くるま</span> as three, and <span lang="ja">ほん</span> as two. A printed label is not separated by spaces between kana. Never replace a kana merely because it looks similar.

### Type with a Japanese keyboard

Enable a Japanese input method (IME) on your device and choose **hiragana** output. For example, entering *neko* and confirming Japanese conversion can produce <span lang="ja">ねこ</span>. Your submitted answer should contain kana, not the Latin letters *neko*. For <span lang="ja">ほん</span>, some IMEs need an additional **n** or conversion confirmation to finish <span lang="ja">ん</span>. IME behavior varies.

If your device does not offer Japanese input, use the visible word cards for reading practice and return to the typing check when a Japanese keyboard is available. The activity accepts exact hiragana labels after trimming outer spaces; it does **not** assess handwriting quality, speed or pronunciation.

### Guided rehearsal

Cover the readings and read <span lang="ja">ねこ</span>, <span lang="ja">くるま</span>, <span lang="ja">みみ</span>, and <span lang="ja">かわ</span>. Then type <span lang="ja">ゆき</span> and compare each kana with its printed model. Finally, try the independent ten-label check without copying from the table.

### Independent check

Type the hiragana for each English picture label. Each response is scored against the one printed label taught above; the model and an explanation appear after submission. You can retry, and your attempt score is saved only on this device. No handwriting or pronunciation grade is implied.
