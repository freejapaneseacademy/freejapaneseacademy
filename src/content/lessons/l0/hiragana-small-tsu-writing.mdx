## Write labels for a library table

Hana is preparing fictional library labels. This is a **writing and typing** activity: you must produce the hiragana, not just recognize it. The small **っ** marks a consonant hold and occupies one mora; full-sized **つ** is a separate syllable. Compare **きて** (“come,” request form, context dependent) and **きって** (“postage stamp”). The words have different meanings and spellings.

## Step 1 — Observe the models

| Meaning | Hiragana | Typical romaji IME input |
| --- | --- | --- |
| postage stamp | **きって** | kitte |
| ticket | **きっぷ** | kippu |
| magazine | **ざっし** | zasshi |
| moon | **つき** | tsuki |
| school | **がっこう** | gakkou |
| park | **こうえん** | kouen |
| big | **おおきい** | ookii |
| teacher | **せんせい** | sensei |

**きって** is **き・っ・て**, three morae; **きて** is **き・て**, two. **つき** starts with full-sized つ. The written **こう** in **こうえん** and **がっこう** represents the おう pattern, while **おおきい** begins with おお. **せんせい** ends in せい, part of the えい spelling pattern. In ordinary speech these spelling patterns often correspond to long vowels, but **do not interchange them in writing**. IME key sequences are examples, not a required keyboard layout; submit converted hiragana.

## Step 2 — Build a two-line notice

The librarian writes:

**きってが あります。** — “There are postage stamps.”

**こうえんは とおいです。** — “The park is far.”

Here **が** marks the thing that exists; **は** marks the topic. Spaces are included to help beginners see word boundaries, although ordinary Japanese generally omits them. **とおい** uses おお, not おう. Copy the model spacing and punctuation for the two sentence questions. The first six questions require only the word, with no spaces or punctuation.

Cover the models and type the eight constrained answers. Your score checks the displayed model spelling after trimming outside whitespace and Unicode NFC normalization; it does **not** judge all possible Japanese sentences or pronunciation. Review each answer explanation before retrying.

## Step 3 — Compose and self-review

Create a fictional two-line library note using the models above, or change one noun while keeping the grammar sensible. For example:

**きってが あります。**

**こうえんは とおいです。**

Compare your note with four criteria: (1) small **っ** appears in words that need it, (2) the written **おう / おお / えい** sequences match the chosen words, (3) **が** and **は** express the intended roles, and (4) each sentence is complete and readable. The optional draft is held in this browser tab and never uploaded. The checklist is learner **self-review**, not teacher or machine grading.
