## Mio's kana-card workshop

**Can-do:** Read, write and identify あ・い・う・え・お, か・き・く・け・こ and さ・し・す・せ・そ. At a classroom table, Sora places fifteen kana cards beside an empty practice sheet. Mio must match each printed shape to its reading, enter it with her Japanese keyboard and compare her own written form. A Latin reading aid is a tool, **not** the Japanese answer.

This is a **script lesson**, not a listening test or a claim to assess pen movements. You can finish all required exercises with a keyboard. Handwriting is optional and self-reviewed.

## Observe the whole set

| Vowels | K row | S row |
| --- | --- | --- |
| <span lang="ja">あ</span> a | <span lang="ja">か</span> ka | <span lang="ja">さ</span> sa |
| <span lang="ja">い</span> i | <span lang="ja">き</span> ki | <span lang="ja">し</span> shi |
| <span lang="ja">う</span> u | <span lang="ja">く</span> ku | <span lang="ja">す</span> su |
| <span lang="ja">え</span> e | <span lang="ja">け</span> ke | <span lang="ja">せ</span> se |
| <span lang="ja">お</span> o | <span lang="ja">こ</span> ko | <span lang="ja">そ</span> so |

Read down each column, then across each row. In common Hepburn romanization <span lang="ja">し</span> is **shi**, not *si*; both *shi* and *si* may work as IME input depending on your keyboard. The target written form is always <span lang="ja">し</span>. The printed shapes here are models for recognition, **not diagrams of the correct stroke sequence**.

## Look for the differences

- <span lang="ja">あ</span> and <span lang="ja">お</span> share some visual features, but <span lang="ja">お</span> has a separate small upper-right mark; compare the complete shapes rather than a single stroke.
- <span lang="ja">き</span> and <span lang="ja">さ</span> can look related at first glance. Locate the horizontal lines and the lower curved part. Typeface styles may join or separate portions; that variation does not create a new kana.
- <span lang="ja">し</span> is a simple descending curve; <span lang="ja">つ</span> is **not** part of this chapter's fifteen characters. Do not confuse a rotated-looking shape with an interchangeable symbol.
- <span lang="ja">す</span> and <span lang="ja">む</span> are different characters. Here you need only <span lang="ja">す</span>; inspect the crossing and lower loop.
- <span lang="ja">せ</span> and <span lang="ja">さ</span> both start with an s sound in reading aids, but their forms and vowel sounds differ.

## Type Japanese, not romaji

Enable a Japanese IME or Japanese keyboard. In romaji-input mode, type a reading such as `ka` and accept the resulting <span lang="ja">か</span>. For <span lang="ja">shi</span>, check that your IME actually produces <span lang="ja">し</span>. Turn off predictive conversion if it replaces a kana with a kanji or an unrelated word; select the hiragana candidate. On a phone, use the kana keyboard or Japanese romaji keyboard as you prefer.

**Guided sequence:** type `a`, `ki`, `shi`, `se` and confirm the output is <span lang="ja">あ・き・し・せ</span>. Then type the complete word <span lang="ja">かさ</span> (umbrella). <span lang="ja">か</span> is *ka* and <span lang="ja">さ</span> is *sa*; neither kana separately means “umbrella.”

## Words from familiar cards

| Card | Kana pieces | Meaning |
| --- | --- | --- |
| <span lang="ja">かさ</span> | か + さ | umbrella |
| <span lang="ja">すし</span> | す + し | sushi |
| <span lang="ja">いす</span> | い + す | chair |
| <span lang="ja">ここ</span> | こ + こ | here, near the speaker |
| <span lang="ja">せかい</span> | せ + か + い | world |

Read each word, then cover the kana column and type it from the reading you remember. Keep your attention on **correct character choice**: typing *kasa* in Latin letters is not the same as entering <span lang="ja">かさ</span>.

## Optional handwriting comparison

If you have paper, draw five equal-size boxes and copy <span lang="ja">あ・か・き・さ・し</span> from the models above. Look for distinct proportions, visible components and consistent size. Compare each result to the printed character. A static glyph does **not** verify conventional stroke order; use an appropriately licensed, character-specific stroke guide before claiming that you have mastered stroke sequence. If you cannot handwrite, typing the same five kana is an equally valid accessible practice path in this lesson.
