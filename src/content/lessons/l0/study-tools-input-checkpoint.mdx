## Your chapter Can-do

**Enter Japanese using a keyboard and control reading aids.** This checkpoint checks practical Japanese input knowledge, printed classroom instructions and spoken meaning. It does not test typing speed, free-writing quality or pronunciation.

You will answer **12 written and reading questions** and **four listening questions** based on two real licensed Japanese dialogues. The two sections save separate scores in your browser. For the strongest listening self-check, play the audio without revealing transcripts first. You may reveal them for accessible assisted practice, which is recorded separately.

## 1. Input, conversion and reading aids

Japanese **input** (入力・にゅうりょく) means entering Japanese text with a keyboard or input method editor (IME). On a typical romaji-input keyboard, entering `neko` with Japanese input active produces <span lang="ja">ねこ</span>. This is a practical example, not a universal shortcut for every device.

**Conversion** (変換・へんかん) offers written **candidates** (候補・こうほ) for a word. When selecting kanji, read the candidates and check their meaning (意味・いみ). The first candidate is not automatically the right one. It is also fine to leave a word in hiragana when that is appropriate.

**Furigana** (ふりがな) shows the reading of a written word. For example, <ruby lang="ja">日本語<rt>にほんご</rt></ruby> is read にほんご. Furigana does not translate the word or change the underlying typed text.

## 2. Polite requests in class

A useful request ends with **〜てください** (please do …). <span lang="ja">見てください。</span> means “Please look.” <span lang="ja">読み方を教えてください。</span> means “Please tell me how to read it.” <span lang="ja">選んでください。</span> means “Please choose/select.” These are polite requests to a person, not computer commands.

Notice the distinction between <span lang="ja">読み方</span> (how to read something), <span lang="ja">意味</span> (meaning), and <span lang="ja">候補</span> (candidate). An unfamiliar written word may need both its reading and its meaning checked.

## 3. Read a short classroom keyboard guide

The following is an original supported handout, adapted for checkpoint reading practice. The interface wording varies by operating system.

> ① まず、日本語の入力をえらびます。
>
> ② ローマ字で `neko` と入力すると、「ねこ」と出ます。
>
> ③ 「ねこ」は、ひらがなのままでもいいです。
>
> ④ 漢字にしたいときは、変換の候補を見て、意味を確認します。
>
> ⑤ 「日本語」の読み方は「にほんご」です。ふりがなは読み方を示します。
>
> ⑥ 小さい「ゃ」と大きい「や」を確認しましょう。「きゃ」と「きや」はちがいます。
>
> ⑦ こまったら、「よみかたを おしえて ください」と聞きましょう。

In English: first select Japanese input; typing `neko` produces ねこ; hiragana can be retained; conversion candidates must be checked for meaning; furigana displays a reading; small ゃ differs from full-size や; and learners can politely ask for a reading. When answering, point to the numbered Japanese sentence that supports your choice.

## 4. Guided production and honest self-review

On your own device, if Japanese input is available, type <span lang="ja">ねこ</span> and <span lang="ja">日本語</span>. Then write or type <span lang="ja">読み方を教えてください。</span> as a classroom request. Compare against three criteria: the kana are recognizable; the request includes ください; and you can explain when to use furigana rather than conversion. This is **ungraded writing practice**. A correct multiple-choice answer is not proof that you can type independently.
