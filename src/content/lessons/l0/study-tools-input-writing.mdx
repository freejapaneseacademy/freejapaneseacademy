## Mission: help a classmate use Japanese input

A fictional student, Emi, is writing a classroom note. The keyboard is showing Latin letters instead of Japanese. A teacher can help, but Emi needs to ask clearly. You will type kana labels, build short requests and write a supported instruction. Do not enter your own name, email or personal information.

**Can-do:** Enter Japanese using a keyboard and control reading aids. This is written production, not a pronunciation test. You can use any device's Japanese IME; exact keys and menus vary by operating system.

## 1. Observe: from input to readable Japanese

An **IME** (input method editor) converts keystrokes into Japanese text. With a common romaji-input setting, typing `nihongo` and confirming the conversion can produce <span lang="ja">にほんご</span> (“Japanese language”). The Latin letters alone are **not** the final kana answer. Some IMEs offer <span lang="ja">日本語</span> as a kanji conversion candidate. Check the candidate's meaning before accepting it.

| Classroom expression | Japanese | Meaning |
| --- | --- | --- |
| Japanese language | <span lang="ja">にほんご</span> | Japanese |
| hiragana | <span lang="ja">ひらがな</span> | hiragana |
| katakana | <span lang="ja">カタカナ</span> | katakana |
| character / letter | <span lang="ja">もじ</span> | written character |
| reading | <span lang="ja">よみかた</span> | how something is read |
| please | <span lang="ja">おねがいします</span> | polite request expression |

**Try it:** Turn on Japanese input, type <span lang="ja">にほんご</span>, then inspect the result. If you use kana input rather than romaji input, the keys differ; the target is the same Japanese text. If your keyboard cannot switch input modes, you can still study the models and paste the kana for practice, but that is not evidence of IME typing fluency.

## 2. Build a polite request

**Model A:** <span lang="ja">にほんごで おねがいします。</span> — “In Japanese, please.” The particle <span lang="ja">で</span> marks the language or means used here.

**Model B:** <span lang="ja">よみかたを おしえてください。</span> — “Please tell me how to read it.” <span lang="ja">を</span> marks what the teacher should explain; <span lang="ja">おしえてください</span> asks for the action politely.

**Model C:** <span lang="ja">ひらがなで かいてください。</span> — “Please write it in hiragana.” Replace <span lang="ja">ひらがな</span> with <span lang="ja">カタカナ</span> to request katakana. Both are possible requests; choose the script that matches the task.

These expressions do not all use identical grammar. <span lang="ja">おねがいします</span> can stand with a noun or circumstance, whereas <span lang="ja">おしえてください</span> and <span lang="ja">かいてください</span> ask someone to do an action.

## 3. Ask about reading aids

**Furigana** are small reading annotations near kanji, not an input mode and not a translation. For example, <ruby lang="ja">日本語<rt>にほんご</rt></ruby> shows a reading of the word. In HTML, ruby markup pairs the base text and reading; in an ordinary note, the beginner can write <span lang="ja">日本語（にほんご）</span>.

**Model:** <span lang="ja">ふりがなを つけてください。</span> — “Please add furigana.” This asks for a reading aid. <span lang="ja">にほんごで おねがいします</span> instead asks for Japanese as the language.

## 4. Write a useful two-step instruction

A simple classroom note can say:

<span lang="ja">まず、にほんごで かいてください。つぎに、よみかたを かくにんしてください。</span>

“First, please write in Japanese. Next, please check the reading.” The instruction does **not** promise that every IME will automatically show furigana; reading annotations are a separate tool.

The punctuation <span lang="ja">、</span> and <span lang="ja">。</span> helps separate steps. In practice tasks below, spaces between Japanese phrases are optional beginner aids.

## 5. Type, check and revise

The writing studio contains **12 constrained Japanese text tasks** with stable IDs, expected spellings and explanations. They test written forms, not free composition. Three longer messages are **self-reviewed**: reveal models and apply the rubric rather than trusting an exact-match grader to judge natural Japanese.

### Self-review rubric

- **Purpose:** Does your note request the right language, script or reading help?
- **Japanese form:** Did the IME produce kana, not unconverted romaji? Did you confirm the chosen candidate?
- **Politeness:** Does your request use an appropriate <span lang="ja">ください</span> or <span lang="ja">おねがいします</span> pattern?
- **Clarity:** Can a classmate tell what to do first and next? Are readings and translations kept distinct?

Use the model as a reference, not as the only acceptable natural sentence. You may revise repeatedly; a self-check is **not** teacher-graded proficiency.

## 6. Common repairs

**Romaji left unconverted:** `hiragana` is not the target <span lang="ja">ひらがな</span>. Check the output after IME conversion.

**Wrong script:** <span lang="ja">カタカナ</span> and <span lang="ja">ひらがな</span> name different scripts. Both may be correct Japanese, but the classroom cue determines which to use.

**Confusing aids:** Furigana tells the reading of a word. It does not translate it. A candidate list from an IME is also not furigana.

**Missing particle:** In <span lang="ja">よみかたを おしえてください</span>, <span lang="ja">を</span> marks what to explain. In <span lang="ja">ひらがなで かいてください</span>, <span lang="ja">で</span> marks the script used.

## 7. Independent writing challenge

Imagine Emi needs a Japanese-script label, asks a teacher to add furigana, then leaves a two-step instruction. Write all three without copying, uncover the models, and revise. Your typed draft stays in the current page session; the numeric constrained-task score is saved locally in your browser when you check. No writing is sent to a server.
